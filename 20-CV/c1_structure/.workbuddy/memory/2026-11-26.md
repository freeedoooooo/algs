## AI/Agent 智能化构思（08:5x，本轮只设计、未改产品代码）
- 用户诉求：结构化工具加 AI/agent，减少操作交互与提取策略对人工配置/固定规则的依赖。先构思，不施工。
- 核心裁决：不重写成通用 AI 抽取平台；在既有确定性骨架上加 Agent 编排层，坚持「AI 只做选/生成/判断，值必须回锚，人只审低置信」。
- 架构五层：交互层（一键处理+异常队列）→ Agent 编排层（归类/生成/路由/校验/回流）→ 确定性执行层（v1/v2 算子、v3 智能抽取、validate、入库映射）→ 资产层（文档模板+字段契约、规则版本快照、更正样本池）→ 唯一事实源（parse.json + 逐格 lineage）。紫色=新增智能层，灰色=既有底座。
- 关键取舍：生成 Agent 输出的是 **spec_version=2 规则**，不是把 LLM 值直接写进暂存；直接写值会架空血缘与可复现性。v3 保留为无规则兜底通道，evidence 匹配不到即留空。
- 分期：P0 生成 Agent（消灭手写 JSON）→ P1 归类+路由 → P2 校验路由+异常队列（L3 成型）→ P3 回流闭环（原设计稿 B/C）。
- 用户拍板（AskUserQuestion）：①一期=生成 Agent；②目标档位=L3 自动+异常；③回流闭环=暂缓。
- 已输出两张架构图（分层架构、自主度阶梯 L1~L4）。
