## 台账紧凑化 + 操作列固定修复 + 全局横向滚动（同日 09:3x~09:4x，用户反馈上轮 sticky 操作列仍在屏外）
- 根因诊断（无浏览器工具，按 CSS 原理）：①table.list 用 border-collapse:collapse，Chrome 下 th/td 的 position:sticky 失效→操作列固定不住被挤出屏外；②table{width:100%}+单元格 nowrap/overflow:hidden 使表恒等于容器宽，内容被截断而非撑开→横向滚动条出不来。
- 统一方案（改 shell.css/shell.js/sources.css/sources.html）：
  · shell.css：table.list 改 border-collapse:separate;border-spacing:0（sticky 可靠）；字号 12px、th padding 5px 8px、td 4px 8px（整体紧凑）；新增 .tblscroll{overflow-x:auto;max-width:100%} 与 .tblscroll>.list{width:max-content;min-width:100%}；末列通用 sticky 规则 `table.list>thead>tr>th:last-child,table.list>tbody>tr>td:last-child{position:sticky;right:0;background;box-shadow}`（表头 z4、hover 同步背景）。
  · shell.js：initColResize 的 setup 开头自动把不在 .tblscroll 且不在 .dpanel/.pipe-panel/.stgmain 内的 table.list 包进 .tblscroll；__colReady 守卫防 MutationObserver 无限回调；排除 .stgmain（preview 有自己的 overflow:auto 方案，且包了会破坏表头 sticky top）。
  · sources.css：删除上轮专属 .tblscroll/.col-act sticky/min-width:960px 规则，改由 shell.css 统一定义；sources.html 手写 .tblscroll 保留（JS 检测不重复包）。
- 验证：node --check OK；CSS/JS 断言（separate、max-content、sticky last-child、auto-wrap、旧规则清除）全过；8799 冒烟 /sources///extract//rules//dashboard//preview 全 200，静态 shell.css/shell.js 含新代码、sources.css 旧规则 gone；验完即停、8799 释放、tmp 空；8765 未动。纯前端，刷新即生效。
- 复用要点：Chrome 下表格 sticky 列必须 border-collapse:separate；要让表格横向滚动必须 width:max-content 而非 100%。
