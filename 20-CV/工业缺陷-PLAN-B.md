## 1. OCR 与工业缺陷的差异（为什么要单独补）

你在 OCR 计划里练出的能力**大部分可迁移**，但工业缺陷有几个 OCR **教不了**的本质差异：

| 维度 | OCR | 工业缺陷 | 缺口 |
|---|---|---|---|
| **监督方式** | 全监督（有标注文字） | **常无标注/缺陷稀少** → 无监督异常检测 | ⭐ 最大缺口 |
| **输出** | 框 + 字符串 | 框 / 掩码 / **异常分数** | 无字符串，不涉 CTC |
| **样本分布** | 数据充足 | **正常样本多、缺陷样本极少**（长尾） | 类别不均衡/少样本 |
| **精度尺度** | 像素级文字 | **微米级/亚像素**缺陷 | 传统CV+标定 |
| **现场** | 服务器/云 | **产线实时 + 相机 + PLC** | 硬件/通信/实时性 |

### 可迁移的部分（你已经会，直接复用）
| OCR 练出的技能 | 工业缺陷等价物 |
|---|---|
| 低质量鲁棒性（模糊/反光/光照） | 反光/磨损/复杂纹理缺陷 |
| 分割式检测（DBNet/小目标） | 微米级/细微缺陷分割 |
| 迁移学习 + 少量域数据微调 | 少量缺陷样本微调 |
| 数据合成/增强 | 缺陷稀少 → 合成/少样本 |
| bad case 攻坚（过检漏检） | **漏检=不良品流出（核心 KPI）** |
| ONNX/TensorRT 部署 | 产线实时推理 |

## 5. D1 · 无监督异常检测（周2-5）⭐ signature skill

> 这是工业缺陷的**核心竞争力**，OCR（全监督）完全教不了。**给足 4 周，别赶。**

### 周2 · 原理 + 跑通
- [ ] 理解无监督异常检测思路：**只学"正常长什么样"，偏离正常即异常**
- [ ] 用 `anomalib` 在 MVTec AD 上跑通 **PatchCore**
- [ ] 理解 PatchCore 核心：**特征嵌入 + 记忆库（memory bank）+ 最近邻距离**
- [ ] 评估指标：**AUROC / AP / F1**（区分**像素级**定位 vs **图像级**判别）

### 周3 · 多方法对比
- [ ] 跑通 **PaDiM**（高斯分布建模）和 **EfficientAD**（轻量实时）
- [ ] 对比三者：原理差异、速度、精度、适用场景
- [ ] 理解"特征嵌入 + 距离度量"这一大类方法的共性

### 周4 · 调优 + 可视化
- [ ] 调参：memory bank 大小、特征层选择、阈值设定
- [ ] 可视化异常热力图（anomaly map），理解"模型认为哪里异常"
- [ ] 分析 bad case：什么缺陷检不出、什么正常样本被误判

### 周5 · 小结 + 竞赛启动
- [ ] 把 D1 成果整理成作品集第一块（README + 方法 + 指标 + 可视化）
- [ ] 🏁 **启动竞赛**：报名一个天池工业质检赛/Kaggle 缺陷赛，本周只做数据探索（EDA）
- [ ] **里程碑**：MVTec AD 上 PatchCore 达标记，能讲清无监督异常检测原理与调优思路
