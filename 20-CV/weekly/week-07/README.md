## 本周定位

你前几周训的都是**全连接（MLP）**：每个神经元看整张图（784 个输入）。这有两个毛病：① 参数爆炸（784×128 就 10 万参数）；② **没有空间结构感**——"猫在左上"和"猫在右下"对 MLP 是两种输入，它得从头学。CNN 用**局部连接 + 权值共享**解决这两个问题，是图像任务的命根子。

> 🔗 **本周 bad case 回看锚点（1h）**：打开 [CNN Explainer](https://poloclub.github.io/cnn-explainer/)，加载一个训练好的小 CNN，看特征图逐层变化。联想你的 bad case：**反光/模糊样本，可能在哪一层的特征图里"信息被洗掉"？**（边缘层？纹理层？）记进日志。这就是"卷积在干什么"和"OCR 真实问题"的桥。

## 学什么 & 怎么学

### 模块 A · 为什么需要 CNN（Day 1）

**概念清单**：

| 概念 | 一句话 |
|---|---|
| 局部连接 | 每个神经元只看一小块窗口（如 3×3），不是全图 |
| 权值共享 | 同一卷积核滑过整张图，参数只有 `kh×kw`，远少于全连接 |
| 平移不变性 | "猫"在哪都能被同一个核 detect，因为核滑遍全图 |
| 层次特征 | 浅层抽边缘→中层抽纹理→深层抽部件/物体 |

**怎么学**：
- 读 d2l 第 6 章（从 LeNet 到卷积）：https://zh.d2l.ai/chapter_convolutional-neural-networks/index.html
- 立刻打开 [CNN Explainer](https://poloclub.github.io/cnn-explainer/) 玩 20 分钟——**可视化是本周最重要的直觉来源**。

**产出**：能回答"卷积相比全连接省参数、有平移不变性，凭什么？"

### 模块 C · 池化 + 多通道卷积（Day 3）

**概念清单**：
- **池化（Pooling）**：把 `pool×pool` 窗口压成 1 个值（max/avg）。降分辨率、抗小位移、减少参数。它**不做学习**（无参数），纯下采样。
- **多通道卷积**：输入有 `C_in` 个通道（RGB 是 3，特征图也是多通道）。**每个输出通道**由一组 `C_in` 个核分别卷后相加得来。核的形状是 `(C_out, C_in, kh, kw)`。

**动手**：
- `ex_conv2d.py` Part2 `max_pool2d`：`TODO 2` 滑窗取最大值。
- Part3 `conv2d_multi`：`TODO 3.1/3.2` 对每个输出通道，把各输入通道卷完相加 + 加偏置；输出 shape 应为 `(C_out, out_h, out_w)`。自检：`(3,8,8)` 输入 + `(3,3,3,3)` 核 → 输出 `(3,6,6)`（因为 8-3+1=6）。

**产出**：池化 + 多通道卷积手写通过；**理解"C_out 个核 → C_out 个输出通道"**。

### 模块 D · 卷积可视化 + 感受野（Day 4-5）

**核心**：卷积核就是"特征探测器"。跑脚手架看效果：

```bash
python b_conv_viz.py
```
它会用 Sobel 边缘核在真实图上抽出轮廓，存 `output/conv_edge_demo.png`。**重点体会：一个 3×3 核，凭权重就定义了"什么是边缘"。** 训练 CNN 的本质，就是**学这些核的权重**。

**感受野（Receptive Field）**：深层一个神经元"看"原图多大区域。例如两层 3×3 卷积叠加，第二层一个神经元对应原图 `5×5`（不是 6×6！）。推算：`RF = 1 + (k-1) + (k-1)` 当 stride=1。

## 常见坑 & 卡住怎么办

- **输出尺寸算错导致滑窗越界**：严格用公式先算 `out_h/out_w`，再建全零输出数组逐窗填，避免索引超界。padding 记得给输入加，不是给输出加。
- **多通道维度搞混**：牢记数据流——输入 `(C_in,H,W)`，每个输出通道 c 用 `kernels[c]` 这 `C_in` 个核分别卷 `C_in` 个输入通道，逐通道加总。输出通道数 = `C_out`。
- **把池化当卷积学**：池化无参数、不可学习，只是固定下采样；卷积核权重是学出来的。别混淆。
- **"手写卷积有什么用，PyTorch 一行 Conv2d 搞定"**：下周（第 8 周）用 `nn.Conv2d` 时你立刻懂"它在算的就是你本周手写的滑窗加权求和"——**理解深度差很多**，且调参/诊断不收敛时你能看懂 shape 怎么变。
- **CNN Explainer 打不开**：它是纯前端网页，换个浏览器或直连；打不开就用 d2l 第 6 章的静态图代替。
- **卡住 >2h**：回 d2l 第 6 章 + CNN Explainer，先照公式把小例子推通，别死磕大图。
