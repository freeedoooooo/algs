# 无影云工作站 · 环境搭建说明（手动执行版）

> **适用**：阿里云无影云工作站（Windows + 带 GPU）。目标是在无影上**一次性**装好
> `Miniconda + ocr 环境(Python 3.10) + GPU 版 PaddlePaddle + PaddleOCR`，
> 让 Week 1 跑通，并且 **P1 训练阶段直接复用，不再重装环境**。
>
> 本文是「文档型」操作手册：每一节都有**目的说明 + 可直接复制的命令 + 预期结果**，
> 你照着逐段在无影的 PowerShell 里粘贴执行即可。

---

## 总体流程一览

```
仓库弄到无影  →  检测 CUDA 版本  →  装 Miniconda  →  建 ocr 环境
     →  装 GPU 版 PaddlePaddle（失败回退 CPU）  →  装其余依赖
     →  冒烟测试  →  跑通 D2（PaddleOCR 识别图片）
```

---

## 步骤 0 · 把本仓库弄到无影

我的执行环境是本地机器，无影是另一台独立远程桌面，我无法直接操作它，
所以你需要先把项目文件拿到无影上（确保 `weekly/week-01/` 存在）：

- 如果是 git 仓库：在无影上 `git clone <你的仓库地址>`（或本地 `git pull` 后同步）；
- 否则用网盘 / 共享目录把整个 `20-CV/` 拷贝过去。

完成后，在无影打开 **PowerShell**，进入本仓库的 `weekly/week-01` 目录：
```powershell
cd <你的仓库路径>\weekly\week-01
```

---

## 步骤 1 · 检测 GPU 与 CUDA 版本（关键）

PaddlePaddle 的 GPU 版必须和显卡驱动支持的 **CUDA 版本**匹配，先看清再装。

```powershell
nvidia-smi
```

看输出右上角一行，类似：
```
| NVIDIA-SMI 551.61    Driver Version: 551.61    CUDA Version: 12.4  |
```
记下 **CUDA Version**（上例是 12.4）。后面步骤 4 按它选对应的安装命令。

- 若 `nvidia-smi` 报错 / 没这行 → 说明无影这台没挂上 GPU，直接按「CPU 版」装（Week 1 仍可用，P1 训练前再处理）。

---

## 步骤 2 · 安装 Miniconda

作用：建一个**隔离的 Python 3.10 环境**，避免把你系统里别的 Python 搞乱。
（PaddlePaddle 只支持到 Python 3.11，本机自带的 3.13 装不上，所以必须新建 3.10 环境。）

如果**已经装了 conda**，跳过这步，直接进步骤 3。

如果没装，下载并静默安装 Miniconda：
```powershell
$url  = "https://repo.anaconda.com/miniconda/Miniconda3-latest-Windows-x86_64.exe"
$inst = "$env:TEMP\Miniconda3.exe"
Invoke-WebRequest -Uri $url -OutFile $inst
Start-Process -FilePath $inst -ArgumentList "/S", "/D=$env:USERPROFILE\miniconda3" -Wait
```
安装完成后，新开一个 PowerShell 窗口，输入 `conda --version` 能显示版本号即成功。

---

## 步骤 3 · 创建 `ocr` 环境（Python 3.10）

```powershell
conda create -n ocr python=3.10 -y
conda activate ocr
python -m pip install --upgrade pip
```
> **之后所有安装命令都要在 `ocr` 环境里执行**（命令行前面显示 `(ocr)` 才对）。
> 每次新开 PowerShell，先 `conda activate ocr` 再操作。

---

## 步骤 4 · 安装 PaddlePaddle（GPU 优先，失败回退 CPU）

**先按步骤 1 看到的 CUDA 版本选一条执行**（已在 `ocr` 环境内）：

| 你的 CUDA 版本 | 执行这条 |
|---|---|
| **11.x**（如 11.8） | `pip install paddlepaddle-gpu==2.6.2 -f https://www.paddlepaddle.org.cn/whl/windows/mkl/avx/stable.html` |
| **12.x**（如 12.4） | `pip install paddlepaddle-gpu==3.0.0 -f https://www.paddlepaddle.org.cn/whl/windows/mkl/avx/stable.html` |
| 没 GPU / 装失败 | `pip install paddlepaddle`（CPU 版，Week 1 够用） |

> ⚠️ 如果上面的 GPU 版安装报错（大多是 CUDA 版本对不上），去
> https://www.paddlepaddle.org.cn/install 按你的真实 CUDA 版本复制官方命令重跑即可；
> 或者先装 CPU 版保底，等 P1 训练前再换 GPU 版。

**验证装好了没**：
```powershell
python -c "import paddle; print(paddle.__version__)"
```
能打印出类似 `3.0.0` 的版本号 = 成功。

## 步骤 5 · 安装本周其余依赖

```powershell
pip install paddleocr pdfplumber pymupdf matplotlib
```
（就是 `weekly/week-01/requirements.txt` 里的内容，手动装一遍等价。）

## 步骤 6 · 冒烟测试

```powershell
python -c "from paddleocr import PaddleOCR; print('PaddleOCR import OK')"
```
看到 `PaddleOCR import OK` = 环境齐活。

## 步骤 7 · 跑通 Week 1 核心（D2 · PaddleOCR 识别图片）

准备一张含**中文**的图片，命名为 `test.png` 放到 `weekly/week-01/` 下，然后：

```powershell
python ocr_image.py
```

命令行打印出图片里的**文字 + 置信度**（如 `你好  置信度=0.98`），Week 1 就跑通了。

> 若报错 `PaddleOCR` 对象没有 `.ocr()` 方法：说明你装的是 PaddleOCR **3.x**，
> 接口从 `.ocr()` 改成了 `.predict()`。改 `ocr_image.py` 里的调用方式，或参考
> 官方仓库 Quickstart（https://github.com/PaddlePaddle/PaddleOCR）最新用法。以官方 README 为准。

## 常见问题

- **`conda` 不是内部命令**：步骤 2 没装好或窗口没刷新，重开 PowerShell 再试；还不行就重装 Miniconda。
- **GPU 版 paddle 装完 `import paddle` 报错**：CUDA 版本不匹配，按步骤 4 的官方链接换对应版本，或先 CPU 版保底。
- **首次运行 PaddleOCR 自动下载模型很慢**：正常，等一次即可；失败就重试。
- **无影其实是 Linux 系统**：命令基本一致，仅 Miniconda 安装换成 Linux 版安装包（`.sh`），其余 `conda` / `pip` 命令完全相同。
