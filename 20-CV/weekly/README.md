# 周计划总索引（OCR 学习计划 · 逐周执行版）

> 本目录是《../OCR学习计划.md》的**逐周落地版**。总计划告诉你"学什么阶段"，这里告诉你"**这一周每天干什么、看哪个链接、跑哪段代码、周末产出什么**"——打开就能照着做，不用再自己上网扒资料。
>
> **用法**：进入对应 `week-NN/` 目录，读 `README.md`，按"逐日安排"推进，周末对照"验收清单"打勾，填"进度日志"。

## 每个周目录里有什么（混合模式）

每周目录 = **一份计划（README.md）+ 一个可动手的本地小项目**：

- `README.md`：周计划正文（8 段结构）
- `notes.md`：你的笔记模板
- `requirements.txt`：本周依赖，`pip install -r` 即可
- **脚手架脚本**（可直接运行）：环境/数据下载/画图/调 API 这类"敲了学不到深度学习"的部分，替你写好，省精力
- **`ex_*.py` 空白练习**（要你自己写）：前向/反向传播/训练循环这类"敲的过程=学习本身"的核心，只给函数签名+TODO+shape提示，**不给答案**

> ⚠️ **学习纪律**：`ex_*.py` 先自己写，卡住超过 2 小时再翻 README 里的"标准答案"或指定资源。抄答案 = 本周价值归零。
>
> 这套"哪些预搭、哪些留空"的规则、以及**如何生成后面几周**，见 → [周计划生成规范.md](周计划生成规范.md)

## 每周 README 的固定结构

1. **本周定位**：这周在整条路线里的位置、前置要求
2. **本周目标**：一句话 + 3-5 条硬指标
3. **逐日安排**：Day1-7 每天干什么，配时长
4. **学什么 & 怎么学**：分模块，每块含【概念清单】【资源链接】【动手任务】【可直接抄的代码】
5. **本周资源清单**：所有链接集中放，点开即用
6. **验收清单**：周末打勾
7. **常见坑 & 卡住怎么办**
8. **进度日志**：本周填写

## 三条铁律（每周都适用）

1. **"本周跑通了什么"不能为空**——只看不写 = 没学。
2. **卡住超过 2 小时就跳过/求助**，标记后继续推进，别原地消耗。
3. **先跑通再理解**：照抄代码看到结果，再回头懂原理。
