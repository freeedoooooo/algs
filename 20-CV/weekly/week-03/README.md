## 学什么 & 怎么学

### 模块 A · 核心概念扫盲（Day 1）

**要搞懂的概念清单**（先读一遍，不求全记住，后面写代码时再深化）：

| 概念 | 一句话理解 |
|---|---|
| 神经元 | 一个"加权求和 + 激活"的小单元：`y = f(w·x + b)` |
| 层 | 一堆神经元排一起；输入层→隐藏层→输出层 |
| 激活函数 | 引入非线性（ReLU/sigmoid/tanh），没有它多层网络等价于一层 |
| 前向传播 | 数据从输入算到输出，得到预测值 |
| 损失函数 | 衡量"预测 vs 真实"差多少（回归用 MSE，分类用交叉熵） |
| 反向传播 | 用链式法则从损失往回算每个参数的梯度 |
| 梯度下降 | 沿梯度反方向更新参数，让损失变小 |
| 学习率 | 每次更新的步子大小；太大发散、太小学不动 |
| 过拟合 | 训练集很好、测试集很差 = 死记硬背没学会泛化 |

> **定心丸**：本路线只需"高中 + 大一"数学，且**懂概念即可，不用手推**。框架（PyTorch）会封装所有计算，你现在用 numpy 手写是为了**理解**，不是为了考试。

**只需补这 4 个**（用 3B1B 可视化，每个看 1 集即可）：
1. **矩阵乘法**：3B1B《线性代数的本质》——理解"矩阵乘法 = 线性变换"。你会用到 `X @ W`（数据乘权重）。
   - https://www.3blue1brown.com/topics/linear-algebra
2. **导数**：3B1B《微积分的本质》第 1-2 集——导数 = 某点的变化率/斜率。

3. **梯度**：多变量时，梯度指向"上升最快的方向"，所以**负梯度 = 下降最快方向**（这就是梯度下降的由来）。

### 模块 C · numpy 手写线性回归（Day 3）⭐第一次动手

**任务**：不用任何深度学习框架，纯 numpy 实现线性回归，亲眼看 loss 下降。

**怎么学**：跟 d2l 3.1-3.3（线性回归 + 从零实现）。下面是**可直接抄的最小实现**，抄完逐行改注释理解：

```python
import numpy as np

# 1. 造数据：y = 2x + 1 + 噪声
np.random.seed(0)
X = np.random.randn(100, 1)
y = 2 * X + 1 + 0.1 * np.random.randn(100, 1)

# 2. 初始化参数（要求梯度的量）
W = np.random.randn(1, 1)
b = np.zeros((1, 1))
lr = 0.1                      # 学习率

def forward(X, W, b):         # 前向传播：预测
    return X @ W + b

def loss_fn(y_pred, y):       # 损失：均方误差 MSE
    return np.mean((y_pred - y) ** 2)

# 3. 训练循环
for epoch in range(100):
    y_pred = forward(X, W, b)
    loss = loss_fn(y_pred, y)

    # 反向传播（手推梯度）：dL/dW = 2/N * X^T (y_pred - y)
    dW = 2 / len(X) * (X.T @ (y_pred - y))
    db = 2 / len(X) * np.sum(y_pred - y)

    # 梯度下降：往负梯度方向更新
    W -= lr * dW
    b -= lr * db

    if epoch % 10 == 0:
        print(f'epoch {epoch:3d}  loss={loss:.4f}  W={W[0,0]:.3f}  b={b[0,0]:.3f}')

# 训练完 W 应接近 2，b 应接近 1
```

**要观察的现象**：
- loss 一路下降（把每个 epoch 的 loss 存下来，用 matplotlib 画曲线）
- W 从随机值慢慢逼近真实值 2，b 逼近 1

**动手加练**：
- 把学习率改成 `1.0`（会震荡/发散）和 `0.001`（学得极慢），观察差别 → 直观理解"学习率"
- 用 matplotlib 画出 loss 曲线：
  ```python
  import matplotlib.pyplot as plt
  plt.plot(losses); plt.xlabel('epoch'); plt.ylabel('loss'); plt.show()
  ```

**产出**：跑出 loss 下降 + W/b 逼近真值；画出 loss 曲线；亲手改学习率看过发散。

### 模块 D · softmax + 交叉熵（Day 4-5）

**概念清单**：
- **softmax**：把一组任意实数分数变成"和为 1 的概率"。`softmax(z_i) = e^{z_i} / Σe^{z_j}`
- **交叉熵损失**：分类任务的损失，衡量"预测概率分布 vs 真实标签"的差距
- **多分类**：输出层有多个神经元，每个对应一个类别的概率

**怎么学**：读 d2l 3.4（softmax 回归）。理解三件事：
1. 为什么分类不用 MSE 而用交叉熵
2. softmax 怎么把分数变概率
3. one-hot 标签是什么

**产出**：能解释"softmax 在干嘛""交叉熵为什么适合分类"。

**1. numpy 手写 softmax 回归**（跟 d2l 3.4-3.6，用 FashionMNIST 或简单数据集）。核心结构：
```python
# 前向： scores = X @ W + b ; probs = softmax(scores)
# 损失： cross_entropy(probs, y_onehot)
# 反向： dW = X.T @ (probs - y_onehot) / N   （softmax+交叉熵的梯度出奇地简洁）
# 更新： W -= lr * dW
```
> 跟着 d2l 的"从零实现"章节敲完整代码，别只看。重点是体会**"softmax + 交叉熵"求导后梯度形式很简洁**（`probs - y`），这是深度学习的经典结论。

## 常见坑 & 卡住怎么办

- **数学看不懂想放弃**：回到"定心丸"——懂概念即可，框架封装计算。**卡超 2h 先看代码，代码跑通了数学直觉往往自然就有了。**
- **手推梯度公式看不懂**：先**照抄代码跑出 loss 下降**（top-down），再回头对着 d2l 的推导理解。先跑通再理解。
- **loss 不下降/变 NaN**：多半是学习率太大，调小到 0.01 试试；或检查梯度符号写反了。
- **softmax 数值溢出**：实现时减去最大值 `z - z.max()` 再取 exp（数值稳定技巧），d2l 里有讲。
- **"这跟 OCR 有啥关系"的怀疑**：这就是为什么每周有 bad case 回看——线性/softmax 回归是所有神经网络的原子积木，P4 的 OCR 检测/识别模型底层全是这套循环。**地基看不见但决定楼能盖多高。**
