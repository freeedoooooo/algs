## 学什么 & 怎么学

### 模块 A · nn.Conv2d 与尺寸推算（Day 1）

**概念清单**：
- **`nn.Conv2d(in_ch, out_ch, kernel_size, stride=1, padding=0)`**：你第 7 周手写的 `conv2d_multi` 的框架版。`out_ch` 个核，每个核 `in_ch×kh×kw` 个参数（远少于全连接）。
- **尺寸公式**（再次用）：`out = floor((in + 2p - k)/s) + 1`。

**动手**：手推 LeNet 在 28×28 上的逐层尺寸，写进 `notes.md`：
```
输入 (1,28,28)
Conv1(1→6, 5x5) : 28-5+1 = 24      → (6,24,24)
MaxPool(2)       : 24/2 = 12        → (6,12,12)
Conv2(6→16, 5x5) : 12-5+1 = 8      → (16,8,8)
MaxPool(2)       : 8/2 = 4         → (16,4,4)
Flatten          : 16*4*4 = 256
FC 256→120→84→10
```
**产出**：能不查文档推任意卷积层输出尺寸。

**动手**：

**要观察到的现象**：
- CNN **收敛更快**（更少 epoch 就到高位）
- CNN **最终更高**（利用局部/平移不变性，参数更高效）

### 周末 · 里程碑：口头解释 + 回看（4-6h）

**1. 调优到满意**（≥92% 最佳，不强求满分）。若偏低：加 epoch、lr 试 0.05/0.2、卷积后加一点 dropout。

**2. 达成 P1-C 里程碑——口头解释三件事**（写进 `notes.md`，这是验收核心）：
- **卷积在做什么**：用局部窗口滑过图像、加权求和，提取局部特征；同一核共享权重 → 平移不变 + 参数少。
- **感受野是什么**：输出特征图上一个神经元"看"原图多大区域；越深感受野越大，对应越抽象的特征。
- **为什么 CNN 适合图像**：图像有局部相关性 + 平移不变性，CNN 恰好利用这两点，比全连接参数少、泛化好。

**3. bad case 回看（1h）**：结合特征图可视化，写一句："我的反光样本可能在浅层特征图就丢了边缘对比度，导致深层拿不到清晰特征。" 记进日志。

**产出（= P1-C 里程碑）**：能跑的 LeNet + 对比 MLP 的结论 + 三句话讲解 + 回看记录。

## 常见坑 & 卡住怎么办

- **shape 对不上（最常见）**：逐层用公式推，把每层 `(C,H,W)` 写在纸上。常见错：忘了 `MaxPool2d(2)` 把 H/W 除以 2；Flatten 前的尺寸算错导致 FC 输入维度不匹配。
- **输入维度错**：CNN 要 `(B, C, H, W)`，FashionMNIST 是单通道 → `(B,1,28,28)`。`data_utils.make_cnn_dataloaders` 已帮你加 channel 维，**别再展平**。
- **准确率不如 MLP**：多半是 epoch 不够或 lr 不合适；CNN 前期可能看着慢，但中后期反超。确认数据归一化、train/val 行为（`model.train()/eval()`）。
- **"既然 PyTorch 一行 Conv2d，第7周手写图啥"**：本周你调 shape、看特征图时，脑子里清楚"底下是滑窗加权求和"，debug 和改结构都快得多。**手写一次的理解，会在 P2/P4 改 backbone、调 DBNet 时反复变现。**
- **卡住 >2h**：回 d2l 第 6 章 + `nn.Conv2d` 文档，先照示例把 LeNet 推通，再改结构。
