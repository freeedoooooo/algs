# 设计（已落地）：无重复表头 + 末尾空列的银行流水续页拼接

> 状态：**已实现（2026-11-20）**，`pipeline/structure.py` 已按本稿改动并验证（见 §8）。
> 目标 case：建设银行流水（`20261119161704_建设银行2022.12流水`，3 页、当前 0 合并）。
> 原则：只放宽「续页」判据，**不改动现有「重复表头」严格通路**（20_multipage 等已验证 case 零回归）；
> 不写死任何 case 的列模板 / 账号 / 日期；判据全部为结构 / 几何 / 通用数据形态，宁可不拼不误拼。

---

## 1. 现状判据与银行为何失败

现有 `_continues(a, b)`（structure.py:130）五道闸，全过才拼：

1. `n_cols` 相等且非零；
2. 同 `coord.space`；
3. `a.coord.exact`；
4. `_cols_aligned`（列左缘 x 逐位差 ≤12px，≥2 对）；
5. `_norm_header(a.headers) == _norm_header(b.headers)`（表头逐字重复）。

建设银行实测（source 空间、exact=True、image 910×1287）：

| 页 | n_cols | 「headers」实际内容 | 表 y0 / y1 |
|---|---|---|---|
| 1 | **17** | 真表头：账号…凭证种类、**凭证号、交易介质编号** | 110 / 978 |
| 2 | **15** | **首行数据**（账号值 44250110…、日期 20221209、金额…） | **73** / 1033 |
| 3 | **15** | **首行数据**（同上形态） | **73** / 862 |

两道闸独立失败：

- **闸 1（列数）**：`clean_table`（pdf.py:76）删「整列全空」的列。第 1 页表头行有「凭证号 / 交易介质编号」文字 → 这两列保留 = 17 列；续页无表头、这两列在所有数据行全空 → 被裁 = 15 列。17 ≠ 15，直接 False。
- **闸 5（表头重复）**：续页**没有**重复表头。`split_header`（structure.py:30）把「第一行填满的行」当表头，于是续页首行**数据**被误标成 `headers`，与真表头不相等 → False。即便列数对齐也过不了。

附带损失：续页首行数据被当成表头后，`rows` 少一行（首行数据丢失），与 108 的首行问题同源。

**几何观察（用于防误拼，而非合并条件）**：续页表从页顶附近开始（y0=73 ≈ 5.7% 页高）；但第 1 页表**不**贴页底（y1=978 ≈ 76%）。
→ 「上一页表贴底」**不能**作为闸（本 case 会误拒）；「续页表贴顶」**可以**作为闸。

---

## 2. 目标

让「相邻页 + 列位置对齐 + 续页贴顶 + 首行是数据（无重复表头）+ 末尾空列被裁」的续表也能合并：
丢重复表头（若有）或回收误标首行（若无），数据顺接，列按**主表布局**补齐到主表宽度。

---

## 3. 新判据（续页分支，与严格分支并列）

`_continues` 改为返回模式而非布尔：`'repeat'`（现严格通路）/ `'headerless'`（新）/ `None`（不拼）。

- **G1 相邻 + 同空间 + exact**：沿用现状（页 p 最后一张表 ↔ 页 p+1 第一张表）。
- **G2 列位置子集对齐（替代「列数相等」）**：
  以主表（链首）列左缘 x 为规范布局；续页各列左缘按**保序单射**匹配到主表列（|Δx| ≤ tol，默认 12px，≥2 对匹配）。
  允许续页缺主表的**若干列**（典型为末尾空列）；不允许续页出现主表没有的列位置。
  银行：续页 15 列 → 主表 0..14；主表 15、16（凭证号/交易介质编号）未匹配 = 被裁的空列。
- **G3 续页贴顶**：续页首表 `y0 ≤ top_frac · 页高`（默认 top_frac=0.10）。续表从页顶 resumes；
  排除「页中部新起的无关表」。页高取 pageRec `image_size[1]`（需把页高传进判据，见 §5）。
- **G4 表头关系二选一**：
  - `norm(续页首行) == norm(主表头)` → `'repeat'`：丢首行（现行为）；
  - 否则续页首行须**像数据**：≥1 格命中通用数据形态（长数字串 ≥6 位 / `YYYYMMDD` 日期 / 带小数点金额），
    且这些格对应的主表头是**非数字标签** → `'headerless'`：**保留首行作为数据**（回收误标行）；
  - 首行既不等主表头、又不像数据（即像另一套文字表头）→ `None`，**不拼**（防把「同版式但不同表」误并）。

G2+G3+G4 共同构成防误拼：列位置对齐（同版式）+ 贴顶（续接位置）+ 首行是数据（确为续行而非新表头）。
不引入日期单调 / 账号一致等内容闸（避免 case 硬编码）；如后续误拼率仍高，再议加可选置信闸。

## 4. 列映射与补齐（`_build_stitched` 扩展）

- 主表宽度 W = 链首 `n_cols`。对每个续页表，用 G2 的保序映射 `cont_col → master_col`。
- 续页每行重建为长度 W：匹配列填原值，未匹配主表列填 `''`；`cells` 同形补 `None` bbox。
- `'repeat'`：丢首行（现行为不变）。`'headerless'`：**首行并入数据**（`data = [headers] + rows`），
  `parts[i].header_dropped=False`，并记 `header_recovered=True` 便于报告/诊断展示。
- 合并表 `n_cols=W`、`headers=主表头`；`row_pages` / 每格 `{page,space}` 沿用现机制（页感知回溯不变）。
- 被裁空列在合并表里以空值存在 → CSV 列数与主表一致，下游下载/报告无需改。

## 5. 改动点与风险分级

| 模块 | 改动 | 风险 |
|---|---|---|
| structure.py `_continues` | 布尔→模式；加 G2 子集对齐 / G3 贴顶 / G4 数据形态 | **中低**：纯判据，严格通路保留 |
| structure.py 新增 `_col_map` | 保序单射 x 匹配（贪心双指针） | **低**：纯函数，可单测 |
| structure.py `_build_stitched` | 按映射补齐到 W；headerless 回收首行 | **低**：只影响新分支产物形状 |
| structure.py `stitch_tables` | 传页高（by_page 存 pageRec 或 height map） | **低**：内部签名 |
| pdf.py `clean_table` | **不改**（裁剪保留，拼接期再补齐） | 无 |
| params / 报告 / 下载 | **不改**（默认开启，无新参数；形状兼容） | 无 |

**最小稳妥核心** = G2 子集对齐 + 补齐 + G4 headerless 回收首行（直接修复银行）；
G3 贴顶 + G4 数据形态为**防误拼护栏**，一并落地（不加则误拼风险上升）。
严格 `'repeat'` 通路逐字保留 → 20_multipage / 103 等零回归。

**不做**：不改 clean_table；不加 case 列模板；不加日期/账号内容闸；不加新参数开关；
不动报告/CSV/下载（合并表形状兼容）。

## 8. 落地结果（2026-11-20，已验证）

默认值按 §6 提案采纳：`tol=12px`、`top_frac=0.10`、数据形态正则＝长数字≥6 / `YYYYMMDD` /
小数金额；headerless 回收首行在报告 stitch 面板以琥珀徽标「无表头续页首行已回收 · 页 …」提示。

实测（stdlib 直接跑 `stitch_tables` + 浏览器端到端）：

- 银行 3 页 → 1 张合并表：`n_cols=17`、`n_rows=29`、`source_pages=[1,2,3]`、
  `parts.header_recovered=[2,3]`、`header_dropped=[]`；续页首行非空值集合守恒（不丢数据）；
  每数据行 cells 的 page 与 row_pages 一致（页感知回溯不丢）。
- 20_multipage（重复表头）：`headers/rows/row_pages/cells/n_rows/n_cols/source_pages`
  与旧产物**逐字相同** → 严格 repeat 通路零回归。
- 反例全过：另一套文字表头→不拼；页中部→不拼；续页多出主表没有的列→不拼；
  缺列子集→headerless 且映射正确。
- 报告端：stitch tab「跨页合并 1」、17 个表头格 / 29 数据行、徽标与「来源页 1、2、3 · 29 行 × 17 列」；
  悬停合并格自动切到对应页并高亮该页 stitchbox、换格清除旧高亮；点击钉住正常。

实现期两点澄清（对 §3/§4 的细化，非偏离）：

1. **G2/G4 的「主表」= 链首**，不是直接前驱。headerless 链中前驱的 `headers` 已是数据
   （含数字），若以前驱为参照，「非数字标签」校验会在第 3 页起失败。故 `stitch_tables`
   把链首 master 传进 `_continues`，G2 子集对齐与 G4 标签校验一律以 master 为准。
2. **被裁空列可在中间，不必在末尾**。银行实测主表第 13、16 列在续页全空被裁，
   保序单射 x 匹配按坐标正确归位（续页 col13→主表 col14），补齐后空值落在真实空列位置。
   验收因此校验「非空值集合守恒」而非「末尾补空」。
