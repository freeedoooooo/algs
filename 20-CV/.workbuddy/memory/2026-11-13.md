## week-01 流水线批量化 + 输出隔离（`weekly/week-01/weekend_pipeline.py`）

**用户需求**：流水线是「整合 b/c/d」的工具，不该每次执行都手改 `INPUT_PDF`；
希望一次跑完 `input/` 下所有 case，且每个输入的结果单独一个目录，不要混在一起。

**实现要点（可复用的设计）**
- 配置区 `INPUT_PDF` → `INPUT_DIR='input'`；`collect_cases()` 扫描 + 排序 + 按 `SUPPORTED_EXTS` 过滤；
  `run_batch()` 循环 `run()`，单 case 失败只记一笔、不中断整批。
- `case_out_dir()` 生成 `output/<文件名去后缀>/`，用一个 `set` 处理 `a.pdf` / `a.jpg` 重名撞车。
  `OUT_JSON` / `OUT_TXT` 从「完整路径」改为「文件名」，由 `save_result()` 拼到各自目录；
  中间页图、表格 HTML 也全部传 `out_dir`。
- 补齐两条分支，否则「所有 case」会漏：**图片直接 OCR**（不清理 input 原图）、
  **CSV/TXT/MD 直接读**。`input/test4.csv` 是 GBK，`read_plain_text()` 按
  `utf-8-sig → gbk → latin-1` 逐个试编码，并把实际编码写进结果。
- 汇总表 `output/batch_summary.{json,txt}` 放 `output/` 根（跨 case 共用）。
- 入口兼容：不带参数 = 跑全目录；带文件 = 单文件；带目录 = 指定目录；`run(path, out_dir=None)` 仍可 import 调用。

**踩到并修掉的口径坑**：`result['tables']` 在 OCR 分支装的是「每页一条检查记录」
（哪怕 0 个表格），文本层 / CSV 分支是「一个元素 = 一张表」。
汇总直接用 `len()` 会把 5 页扫描件虚报成 5 个表格 → 新增 `count_tables()` 区分。

## d 脚本输入 test3_image.pdf 报 IndexError（同日晚）

**现象**：内容块日志正常，但 `res.save_to_html(path)` 抛 `IndexError: list index out of range`，
`output/d_table_ocr/test3_image/` 空目录（第一个结果就崩了）。
**根因**：paddlex 3.7.0 `mixin.py:555` 是 `html[list(html.keys())[0]]`；
`PPStructureV3Result._to_html()` 在 `table_res_list` 为空时返回 `{}`。
5 页 PDF 一页一个结果，证书扫描页没有表格 → 越界；一页多表时该方法还只写第一张。

**修法**：`d_table_ocr.py` 新增 `export_html(res, path)`，不再调 `save_to_html()`：
读 `res.html` → 空则从 `[table]` 内容块 `block_content` 兜底 → 仍空返回 `[]` 跳过并打印序号；
多表按 key 拆文件；自己用 utf-8 写文件 + `ensure_readable_html()` 补 charset。
`main()` 汇总写出的文件数与无表格页序号。`weekend_pipeline.table_ocr_page()` 加 `result[0].html` 判空守卫。
文档同步 `README.md`（模块 D 示例代码加 `if res.html:` + 多页说明）、`notes.md`（新增小节）。

**验证**（不加载模型）：两脚本 `py_compile` 通过；用 FakeRes 模拟
① 无表格页 → 返回 `[]`；② 官方字典空但有 `[table]` 块 → 兜底写出且 charset/无嵌套/中文正确；
③ 一页两张表 → 拆成 `c_table_3.html` / `c_table_7.html`；④ 单表 → 原文件名；
⑤ weekend 守卫：空 html 跳过不崩、非空照常写 `pipeline_table_p1.html`。
