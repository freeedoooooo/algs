# 《备菜不慌》微信小程序产品需求与技术架构文档 (PRD)

## 一、 产品愿景与定位
- **产品名称**：备菜不慌（暂定，可替换为“开饭清单”/“好好吃饭·备菜助手”）
- **产品Slogan**：不用想，照着做，新手也能高效搞定一日三餐
- **核心定位**：AI驱动的家庭饮食决策与烹饪效率管理工具
- **核心价值**：解决新手做饭“决策难、统筹差、管理乱”三大痛点，将做饭从费脑家务变成高效通关游戏

## 二、 核心痛点与解决方案

| 新手痛点 | 传统菜谱APP解法 | 本产品降维解法 |
| :--- | :--- | :--- |
| 决策瘫痪：不知吃啥、不懂时令 | 海量菜谱让用户自己搜 | AI一键生成菜单，结合库存+时令+偏好直接给答案 |
| 手忙脚乱：炒到一半发现没切葱 | 只给食材列表，不指导准备 | 烹饪前强制TodoList，备齐再开火 |
| 效率极低：线性做菜耗时2小时 | 步骤线性排列 | 多线程统筹算法，规划最优时间轴缩短总时长 |
| 库存黑洞：食材过期、重复购买 | 无管理或纯手动录入 | AI拍照秒入库 + 做菜自动扣减 + 临期预警 |

## 三、 核心功能模块 (PRD)

### 3.1 智能决策引擎
- **一键推荐**：点击“今日推荐”，AI生成1荤1素1汤或2菜1汤组合
- **场景筛选器**：⚡快手菜(<15min) / 🍳简单菜(零失败) / 🍲周末大菜(硬菜)
- **双轨推荐开关**：
  - 模式A：清库存优先（基于临期食材生成菜谱）
  - 模式B：时令优先（基于当月时令蔬果生成菜谱）

### 3.2 新手高效烹饪导航 🔥核心亮点
- **烹饪前Checklist**：
  - 分三类：【主料/配料】【调料】【工具】
  - 全部打勾后才解锁“开始烹饪”按钮
- **多线程统筹步骤**：
  - 时间轴/并行任务展示，打破线性菜谱
  - 示例：`[00:00]炖汤40min → [05:00]切配菜 → [15:00]调料汁 → [35:00]炒青菜 → [40:00]汤出锅`
  - 关键节点内置悬浮倒计时，到点语音/震动提醒

### 3.3 AI冰箱与库存管理
- **AI拍照入库**：识别种类+数量+保质期，默认拍照时间为购买时间，支持手动修改
- **智能临期预警**：按食材特性自动分类保质期，临期前1-2天推送提醒并加入推荐高权重池
- **做菜自动扣减**：点击“完成烹饪”后，根据菜谱BOM表自动扣减库存

### 3.4 家庭共享与个性化
- **家庭组**：邀请家人加入，库存共享，操作记录可见
- **偏好忌口**：设置过敏源、口味、排除食材，AI推荐与步骤自动适配

## 四、 技术架构（开箱即用）

### 4.1 技术栈
- **前端**：微信原生小程序 (WXML/WXSS/JS)
- **后端**：微信云开发 (CloudBase) Serverless
  - 云数据库：NoSQL文档库
  - 云存储：食材图片
  - 云函数：业务逻辑 + 定时任务
- **AI能力**：
  - 图像识别：腾讯云混元视觉版 / 通义千问VL
  - 菜谱统筹生成：腾讯云混元LLM / 通义千问

### ⚠️ 落地前必做清单

1.  **名称查重**：在微信公众平台后台搜索目标名称，确认未被占用；若被占用，立即切换备选名
2.  **商标预检**：在国家知识产权局商标局官网查询第9类（APP/小程序）和第42类（技术服务）是否可注册
3.  **云开发开通**：注册小程序后第一时间开通云开发环境，选择“按量付费”模式
4.  **AI接口申请**：提前申请多模态大模型API Key（腾讯云/阿里云均有免费额度），避免开发时卡住
5.  **订阅消息模板**：在小程序后台申请“食材临期提醒”“今日菜单推荐”两个订阅消息模板，这是过期提醒功能的合规前提
