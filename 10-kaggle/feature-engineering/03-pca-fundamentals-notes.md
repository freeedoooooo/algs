# PCA 基础概念笔记

> 来源：Kaggle 特征工程课程学习过程中的问答整理
> 主题：PCA 核心思想、载荷、方差、特征分解、特征向量直觉、主成分排序

---

## 一、核心思想：用"变化的轴"代替原始特征

```
原始描述：鲍鱼 = (Height, Diameter)
PCA描述：鲍鱼 = (Size, Shape)
```

- 数据的主要"变化模式"本身就可以作为新特征；
- **不要描述数据"是什么"，要描述数据"怎么变"。**

---

## 二、载荷（Loadings）：符号与幅度

```
Size  = 0.707 × Height + 0.707 × Diameter    （同符号 → 同向变化 → "大小"）
Shape = 0.707 × Height - 0.707 × Diameter    （反符号 → 反向变化 → "形状"）
```

- **符号**决定成分的含义：同号 = 特征同向变化；异号 = 特征反向变化；
- **幅度**决定贡献度：幅度相同 = 各特征贡献均等。

---

## 三、关键区分：载荷 ≠ 方差（最容易困惑的点）

| 概念 | 含义 | 例子中的值 |
|------|------|-----------|
| 载荷 | 原始特征**如何组合**成成分（权重） | 两个成分都是 0.707 |
| 方差 | 数据沿该成分**分散多少**（信息量） | Size 80%，Shape 20% |

- 载荷相同 ≠ 方差相同：载荷是"组合配方"，方差来自**数据本身的分布**；
- 数据中 Height 与 Diameter 大多同向变化 → Size 方向分散宽（方差大），Shape 方向分散窄（方差小）。

---

## 四、0.707 的几何含义

```
0.707 ≈ √2/2 = cos(45°)
```

- 载荷是**新轴与原始轴夹角的余弦**（方向向量的分量）；
- 两个载荷相等 → 新轴位于原始轴的角平分线 → PCA 把坐标系**旋转了 45°**；
- 约束：载荷平方和 = 1（单位向量），0.707² + 0.707² = 1。

---

## 五、特征分解：PCA 的数学引擎

```
协方差矩阵 → 特征分解 → 特征值（方差大小） + 特征向量（方向/载荷）
最大特征值对应的特征向量 = 第一主成分（PC1）
```

- 数学目标：找单位方向 w 使投影方差 `w Cov w` 最大 → 拉格朗日求解 → 恰好得到特征方程 `Cov w = λ w`；
- 因此**特征向量 = 数据最分散的方向，特征值 = 该方向的方差**；
- 几何：协方差矩阵描述数据的"椭圆形状"，特征分解找到椭圆的长轴与短轴。

---

## 六、特征向量的直觉：变换后"方向不变"的方向

- 矩阵变换通常会扭曲空间（旋转 + 缩放），大多数向量方向会改变；
- **特征向量 = 只被缩放、不被旋转的特殊方向**（变换的"主轴"）；
- 类比（拉伸照片）：横向拉伸一张照片，横线方向不变只变长（特征向量，特征值=拉伸倍数），
  竖线方向不变（特征值=1），斜线被扭曲（不是特征向量）；
- 对协方差矩阵而言，这些"主轴"就是数据分布的自然坐标轴。

---

## 七、主成分的排序

```
特征值从大到小：λ₁ > λ₂ > ... > λₙ
PC1 = v₁（最大特征值的特征向量），PC2 = v₂，依此类推
```

降维 = 保留前 k 个主成分，丢弃方差小的成分（信息损失最小）。

---

## 八、为什么"方差大 = 信息多"

**信息 = 差异。没有差异就没有信息。方差就是差异的度量。**

- 方差 = 0：所有点坐标相同 → 无法区分谁是谁 → 信息量 0（如"是否是人类"）；
- 方差大：坐标差异明显 → 区分度高 → 信息多（如身高）；
- 投影到某方向后方差小 → 该方向几乎无差异 → 丢弃它损失最小。

## 九、一页速记

| 困惑 | 澄清 |
|------|------|
| 载荷相同为何方差不同？ | 载荷=组合配方，方差=数据分散程度，两回事 |
| 0.707 是什么？ | cos(45°)，旋转角的余弦 |
| 特征向量为何特殊？ | 变换后方向不变（只缩放），是数据分布的主轴 |
| 主成分是谁？ | 特征值从大到小排序对应的特征向量 |
| 方差大=信息多？ | 信息=差异，方差是差异的度量 |
