# PCA 应用与多重共线性笔记

> 来源：Kaggle 特征工程课程学习过程中的问答整理
> 主题：Explained Variance 图表、PCA 四种应用、多重共线性问题与解决

---

## 一、Explained Variance 图表解读

### 1.1 两张图的用途

PCA 做完后，用这两张图回答一个问题：**"降维后丢了多少信息？"**

### 1.2 左图：% Explained Variance（每个成分解释了多少方差）

| 成分 | 占比 |
|---|---|
| Size | ~96% |
| Shape | ~4% |

原始数据（Height 和 Diameter 两个维度）中所有的"差异/变化"，PCA 重新组织后，**Size 扛了 96%，Shape 只扛了 4%**。

类比：一张照片，**Size 是拉伸方向**（长宽一起变大变小），**Shape 是变形方向**（一个方向拉长另一个方向压扁）。数据点 96% 的差异是因为整体大小不同，只有 4% 是因为形状不同。

### 1.3 右图：% Cumulative Variance（累计方差）

这是左图的累加：
- 只保留 Size → 保留 96% 的信息
- 保留 Size + Shape → 100%（两个全保留）

### 1.4 实际用途：决定降到几维

有 100 个特征，PCA 后看累计方差图：
- 前 10 个成分累计到 95% → 砍掉后面 90 个，只留 10 个
- 信息丢了 5%，但维度从 100 降到 10，模型训练快 10 倍

本例中只保留 Size 一个成分，用 1 个维度代替原来 2 个，只丢 4% 信息。

## 二、PCA 成分的四种应用

PCA 产生的成分本身可以直接当特征用，比原始特征更好。

### 2.1 降维（Dimensionality Reduction）

特征高度相关（多重共线）时，PCA 把"重复信息"挤到方差接近 0 的成分里，直接删掉。

类比：两个人描述同一件事说了 100 句，95 句在重复。PCA 把重复部分压缩成 5 句，丢掉废话。

### 2.2 异常检测（Anomaly Detection）

正常数据的变化集中在大方差成分里，**异常数据往往藏在方差很小的成分里**。

类比：工厂流水线 99% 的产品差异只是"大小略有不同"（大方差成分）。偶尔有个产品"形状扭曲了"——在原始维度看不出来，但在 Shape 这个只占 4% 方差的小成分里非常明显。

#### 为什么是小方差方向？

**大方差方向 = 常见变化模式**

房子面积大 → 地下室也大（正常，大家都这样）
房子面积小 → 地下室也小（正常，大家都这样）

这个方向上数据分散得开（方差大），因为大部分差异都集中在这里。点在这个方向上偏移中心，不算异常，只是"大房子"或"小房子"。

**小方差方向 = 罕见变化模式**

房子面积小 → 地下室却大（反常，很少见）
房子面积大 → 地下室却小（反常，很少见）

这个方向上数据挤在一起（方差小），因为绝大多数点都接近中心。一旦有点在这个方向上偏移，就是"不常见的组合"→ 异常值。

**几何直觉**

```
        PC2（小方差）
        ↑
        ·  ← 异常点（在小方差方向上偏离中心）
        |
   ·····|·····  ← 大部分点挤在中心附近
        |
        ·  ← 异常点
————————|————————→ PC1（大方差）
   ·    |    ·
  ·     |     ·    ← 这个方向上点分散得开，偏离中心不算异常
 ·      |      ·
```

**一句话：异常值 = 在"罕见模式"（小方差成分）上得分极端的点。**

PCA 的价值：原始特征里看不出来的异常（单个特征都正常），在小方差成分上一眼就能看到。

#### 用 z-score 比较不同方向的异常程度

大方差和小方差方向的偏离不能直接用数字对比，需要用 z-score（偏离了几个标准差）。

```
PC1 标准差 = 3，PC2 标准差 = 0.3

点 A：PC1 = 6    → z = 6/3 = 2 个标准差
点 B：PC2 = 0.6  → z = 0.6/0.3 = 2 个标准差
```

直接比：6 > 0.6 → A 更远？
z-score 比：都是 2 → 罕见程度相同。

**z-score 判断标准：**

| z 值 | 含义 |
|---|---|
| < 2 | 正常（95% 的点都在这里） |
| 2-3 | 可疑 |
| > 3 | 异常（99.7% 的点都不到这里） |

**z-score 相同，但业务含义不同：**

| | PC1 z=3（大方差） | PC4 z=3（小方差） |
|---|---|---|
| 统计罕见度 | 一样（0.3%） | 一样 |
| 业务含义 | 极端但可解释（超大房子） | 违反数据结构（小房子大地下室） |
| 需要调查吗？ | 通常不需要 | **需要** |

大方差方向的极端值 = "这个类型里的极端"（高个子）
小方差方向的极端值 = "不该出现的组合"（体温 39°C）

### 2.3 降噪（Noise Reduction）

多个传感器读数共享同一个背景噪声。PCA 把"真正的信号"集中到少数成分，噪声留在低方差成分中，丢掉即降噪。

类比：10 个人同时录音，每个麦克风都有底噪。PCA 把"大家共同听到的声音"提取出来（信号），把"各自麦克风的嘶嘶声"分离出去（噪声）。

### 2.4 去相关（Decorrelation）

有些算法（线性回归等）在特征高度相关时会出问题。PCA 把相关特征变成**互相正交（相关系数为 0）的成分**，算法更好处理。

类比：原来用"身高+体重+腰围"三个高度相关特征预测，PCA 变成"整体体型+胖瘦比例+其他"三个互不重叠的维度，各管各的。

## 三、多重共线性：为什么特征高度相关会出问题

### 3.1 直观理解

预测房价，特征用 `房屋面积（㎡）` 和 `房屋面积（平方英尺）`。两者本质同一件事，相关系数接近 1.0。

模型困惑：**"房价涨，到底是面积的功劳，还是平方英尺的功劳？"** 没法分配权重，系数剧烈波动——训练集上面积权重 5000，换批数据可能变 -3000。

### 3.2 方程组类比

线性回归本质是解方程组，用数据点拟合超平面，求每个特征的系数。

| 方程组 | 线性回归 |
|---|---|
| 未知数 x, y | 特征系数 w1, w2 |
| 方程个数 = 数据量 | 每个样本一个方程 |
| 方程之间独立 → 唯一解 | 特征之间独立 → 系数稳定 |
| 方程之间成倍数 → 无唯一解 | 特征之间高度相关 → 系数不稳定 |

**情况A：特征独立（方程独立）**
```
x + y = 10
x - y = 2
```
解唯一：x=6, y=4。右边各加 0.1 → x=6.1, y=4.0。**扰动 0.1，系数只变 0.1。稳定。**

**情况B：特征高度相关（方程成倍数）**
```
x + y = 10
1.00x + 1.01y = 10.01
```
解：x=0, y=10。第二条右边从 10.01 变 10.02 → 解变成 **x=-1, y=11**。

**扰动只有 0.01，但 x 从 0 跳到 -1，y 从 10 跳到 11。系数翻了天。**

### 3.3 几何直觉

- **独立特征**：两条线交叉成一个角度，交点很"结实"，线稍微动一点，交点只挪一点点
- **高度相关**：两条线几乎平行，交点很远且很"脆弱"，线稍微动一点，交点就滑出去很远

### 3.4 PCA 怎么解决

PCA 把相关特征变成**正交（互相垂直、相关系数为 0）的成分**。每个成分独立携带信息，不存在"功劳分配"问题，系数稳定可解释。

## 四、一页速记

| 困惑 | 澄清 |
|------|------|
| Explained Variance 图看什么？ | 每个成分扛了多少信息量，决定保留几个成分 |
| Cumulative Variance 图看什么？ | 累计到多少成分能覆盖 95% 信息，用于定降维目标 |
| PCA 成分能当特征用吗？ | 能，且往往比原始特征更好（降维/异常检测/降噪/去相关） |
| 多重共线性为什么有害？ | 特征高度相关 → 系数无法唯一确定 → 数据微扰系数剧变 |
| 方程组类比 | 独立方程→唯一解（稳定）；成倍数方程→无数解（不稳定） |
| PCA 如何解决共线性？ | 把相关特征变成正交成分，各管各的，系数稳定 |
