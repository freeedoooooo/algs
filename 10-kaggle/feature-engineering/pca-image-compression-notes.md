# PCA 图像压缩笔记

> 来源：Kaggle 特征工程课程学习过程中的问答整理
> 主题：图像高维向量、两种 PCA 应用对比、低秩近似、压缩原理、真实场景限制

---

## 一、图像 = 高维向量

- 100×100 灰度图拉平（flatten）= 10000 维向量，每个像素一个维度；
- 2000×2000 图 = 4,000,000 维。

---

## 二、两种应用：样本定义不同，数学相同

| | 应用1：数据集 PCA | 应用2：单图 SVD（低秩近似） |
|---|---|---|
| 样本 = | 一整张图片（1000 个） | 图片的一行扫描线（2000 个） |
| 特征 = | 像素位置（4,000,000 个） | 行内像素（2000 个） |
| 模板含义 | 跨图片共性（特征图/特征脸，稠密整图） | 图内共性（典型行模式） |
| 系数含义 | 描述一张图 | 描述一行 |
| 模板归属 | 全数据集共享（存一次） | 单图私有 |
| 利用的冗余 | 图与图相似 | 行与行相似 |
| 需要数据集 | 需要 | 不需要（单张即可） |
| 模式类比 | 印刷厂：制版一次，批量印刷 | 手绘：每张自给自足 |

**PCA 不知道"样本"是什么——数据摆成矩阵的方式决定成分的含义。**

---

## 三、低秩近似：成分图加权叠加

```
M ≈ σ₁(u₁⊗v₁) + σ₂(u₂⊗v₂) + ... + σₖ(uₖ⊗vₖ)
```

- 每一项 `uᵢvᵢ`（外积）= 一张 2000×2000 的秩1"成分图"（模糊的幽灵图）；
- 还原 = k 张成分图按权重 σᵢ 加权叠加；
- k 从小到大：k=1 一团光影 → k=10 大致轮廓 → k=100 清晰可辨；
- 成分图不必整张存储：存 uᵢ(2000) + vᵢ(2000) + σᵢ(1) 即可现场算出外积。

---

## 四、压缩从哪来：统一存储公式

```
每个成分的存储 = 模板长度 + 样本个数（σ 可合并进系数）
总存储 = k × (特征维度 + 样本数)
```

| | 应用1 | 应用2 |
|---|---|---|
| k | 50 | 10 |
| 特征维度 | 4,000,000 | 2000 |
| 样本数 | 1000 | 2000 |
| 每成分存储 | 4,000,000 + 1000 | 2000 + 2000 (+1) |
| 总计 | 200,050,000 | 40,010 |
| 每样本边际成本 | 50 个系数 | 10 个系数 |

- 应用2 的 `(2000+2000)`：第一个 2000 = 行模板 vᵢ，第二个 2000 = 2000 行各自的系数 uᵢ；
- 应用1 的模板是**稠密整图**（4,000,000 数/个），拆不成 (m+n)；其"第二个数"是 1000 张图各自的系数（换个角度看即"每图 50 个系数"）；
- 压缩的本质：**秩 k = 所有行躺在 k 维子空间里**，冗余（行间的线性相关）被只存一份模板 + 每行配方取代；
- 前提：数据必须有冗余；纯噪声矩阵满秩，不可压缩。**信息=差异，冗余=没差异=可压缩。**

---

## 五、整图直接 PCA 不可行时的两条路

- 直接对 4,000,000 维做 PCA：协方差矩阵 128TB、O(d³) 计算 → 不可能；
- 路1 **切块**（工业做法）：8×8 小块独立处理，JPEG 的 DCT 就是块上的"固定模板"；
- 路2 **对偶技巧**：n < d 时先分解 n×n 的 Gram 矩阵再换算（Eigenfaces 论文的做法）。

---

## 六、新照片与真实场景

- 模板学好后如"训练好的模型"：新图只需投影（`pca.transform`），不用重学；
- 前提是**同分布**（同类图片），不是"只能压库内图"；
- 不同类 → 重建误差大 → 可检测并兜底（换码本 / 改用通用编码器）；
- 题材漂移 → 定期重学或 IncrementalPCA 增量更新。

**真实世界不这么做的原因：**

1. 50 个系数还原 400 万像素 = 8 万倍压缩 → 糊到认不出，证件照等高精度场景不可接受；
2. PCA 全局基对对齐敏感（人脸偏 1 像素系数全变）；码本私有无法标准化；误差集中在身份关键的高频细节；
3. 存储/传输实际用 JPEG / JPEG2000 / WebP（分块 DCT/小波 + 感知模型 + 标准化）；
4. "存系数"在真实系统里用于**识别而非还原**：人脸特征向量（128~512 维）只做比对，
   且故意不可还原原图（隐私保护特性）。

## 七、一页速记

| 困惑 | 澄清 |
|------|------|
| 两种图片 PCA 的区别？ | 样本定义不同：整图 vs 扫描行；共享 vs 私有 |
| 压缩本质？ | k×(特征维度+样本数) < m×n，压的是冗余 |
| 真实压缩用 PCA 吗？ | 存储用 JPEG 系；PCA 式系数用于识别且故意不可还原 |
