## 一、载荷（Loadings）代码解读

### 1.1 代码在做什么

```python
loadings = pd.DataFrame(
    pca.components_.T,           # 转置载荷矩阵
    columns=component_names,     # 列名 = PC1, PC2, PC3, PC4
    index=X.columns,             # 行名 = 原始特征名
)
```

`pca.components_` 的形状是 `(4, 4)`，每一行是一个主成分，每一列对应一个原始特征。**转置后**变成：行是原始特征，列是主成分——这样读起来更直观。

### 1.2 载荷表

```
              PC1        PC2        PC3        PC4
highway_mpg  -0.492     0.771     0.070    -0.398
engine_size   0.504     0.627     0.020     0.594
horsepower    0.500     0.014     0.731    -0.464
curb_weight   0.503     0.113    -0.678    -0.523
```

每个数字的含义：**这个原始特征对该主成分的贡献权重**。

### 1.3 怎么看载荷表

**看 PC1 这一列：**

| 特征 | 载荷 | 符号 |
|---|---|---|
| highway_mpg | -0.492 | **负** |
| engine_size | +0.504 | 正 |
| horsepower | +0.500 | 正 |
| curb_weight | +0.503 | 正 |

三个正、一个负，且幅度差不多（都在 0.5 左右）。说明：
- engine_size、horsepower、curb_weight **同向变化**（一起变大）
- highway_mpg **反向变化**（它们变大时，mpg 变小）

翻译成人话：**PC1 = "大排量 + 大马力 + 车重 vs 高油耗效率"**
- PC1 得分高的车 → 排量大、马力大、车重、油耗差 → **豪华/性能车**
- PC1 得分低的车 → 排量小、马力小、车轻、油耗好 → **经济型车**

所以叫它 **"Luxury/Economy" 轴**。

**看 PC3 这一列：**

| 特征 | 载荷 |
|---|---|
| horsepower | **+0.731** |
| curb_weight | **-0.678** |
| highway_mpg | +0.070 |
| engine_size | +0.020 |

horsepower 和 curb_weight 幅度最大，且**异号**。说明 PC3 捕捉的是"高马力低车重 vs 低马力高车重"的对比 → **运动型车 vs 旅行型车**。

### 1.4 载荷的符号和幅度规则

| 观察 | 含义 |
|---|---|
| **同号** | 这些特征沿该成分**同向变化** |
| **异号** | 这些特征沿该成分**反向变化**（形成对比） |
| **幅度大** | 该特征对该成分**贡献大** |
| **幅度接近 0** | 该特征与该成分**几乎无关** |
| **幅度都差不多** | 各特征**均等贡献** |

## 二、载荷矩阵 = 坐标变换矩阵

### 2.1 三者的关系

```
原始数据 X（原始坐标系）  ×  载荷矩阵（变换矩阵）  =  PCA 数据（新坐标系）
```

用矩阵乘法表示：

$$X_{pca} = X_{scaled} \times W$$

其中 $W$ 就是 `pca.components_.T`（载荷矩阵的转置）。

### 2.2 类比：旋转坐标系

想象平面上有一堆点，原来用 (x, y) 描述。PCA 做的事：**把坐标轴旋转到数据最分散的方向**。

- **载荷矩阵** = 旋转矩阵（告诉你新轴相对于旧轴的角度）
- **X_pca** = 同一批点，只是换了一套坐标系来描述

### 2.3 对应关系

| 概念 | 数学角色 | 本例 |
|---|---|---|
| 原始特征 | 旧坐标系的基向量 | highway_mpg, engine_size, horsepower, curb_weight |
| 载荷矩阵 | 坐标变换矩阵（旋转+缩放） | `pca.components_.T`，4×4 |
| PCA 成分 | 新坐标系的基向量 | PC1, PC2, PC3, PC4 |
| X_pca | 数据在新坐标系下的坐标 | 每行 4 个值，是投影后的坐标 |

### 2.4 为什么能解决多重共线性

载荷矩阵的每一列（PC1、PC2...）就是协方差矩阵的**特征向量**。特征向量互相正交 → 新坐标系的轴互相垂直 → 新特征之间不相关。

**PCA 本质上就是把数据旋转到了一个"特征之间互不相关"的坐标系里。**

## 三、Explained Variance 图表解读

### 3.1 左图：% Explained Variance

| 成分 | 占比 |
|---|---|
| PC1 | ~85% |
| PC2 | ~7% |
| PC3 | ~6% |
| PC4 | ~2% |

PC1 一个成分就扛了 85% 的信息，说明这四个特征高度相关，大部分差异可以用一个"Luxury/Economy"维度概括。

### 3.2 这个值怎么算出来的？是特征值吗？

**是，但有归一化。**

PCA 对标准化后的数据算协方差矩阵，然后做特征分解：

$$协方差矩阵 \xrightarrow{特征分解} 特征值 \lambda_1, \lambda_2, \lambda_3, \lambda_4$$

每个特征值 = 对应主成分方向上的方差大小。

**Explained Variance Ratio 的计算：**

$$\text{PC}_i \text{ 的占比} = \frac{\lambda_i}{\lambda_1 + \lambda_2 + \lambda_3 + \lambda_4}$$

因为数据已经标准化，每个原始特征方差 = 1，四个特征总方差 = 4。所以：

$$\lambda_1 + \lambda_2 + \lambda_3 + \lambda_4 = 4$$

从图中反推：
- PC1: 85% → $\lambda_1 \approx 3.4$
- PC2: 7% → $\lambda_2 \approx 0.28$
- PC3: 6% → $\lambda_3 \approx 0.24$
- PC4: 2% → $\lambda_4 \approx 0.08$

**特征值越大 = 该方向上数据越分散 = 信息越多。**

### 3.3 右图：% Cumulative Variance（累计方差）

这是左图的**累加**：

| 保留到 | 累计占比 | 含义 |
|---|---|---|
| PC1 | 85% | 只用 1 个维度，保留 85% 信息 |
| PC1+PC2 | 92% | 用 2 个维度，保留 92% |
| PC1+PC2+PC3 | 98% | 用 3 个维度，保留 98% |
| 全部 | 100% | 不降维 |

**用途：决定降到几维。** 比如你想保留 95% 的信息 → 看折线图，到 PC3 才超过 95% → 降到 3 维。

### 3.4 方差大 ≠ 对预测目标有用

PC1 虽然方差最大（85%），但 PC2/PC3/PC4 尽管方差小，和 `price` 仍有显著的 MI 分数。

**方差大只说明该成分解释了数据本身的大部分变化，不代表它对预测目标最有用。** PC2/PC3 里可能藏着 PC1 没捕捉到的有用信号。

## 四、用 PCA 成分构造新特征：sports_or_wagon

### 4.1 PC3 的业务含义

PC3 载荷显示 horsepower（+0.731）和 curb_weight（-0.678）异号且幅度最大 → **运动型车 vs 旅行型车**。

按 PC3 排序后看数据：

| 品牌 | 车型 | 马力 | 车重 |
|---|---|---|---|
| porsche | hardtop | 207 | 2756 |
| porsche | convertible | 207 | 2800 |
| jaguar | sedan | 262 | 3950 |
| mercedes-benz | wagon | 123 | 3750 |
| peugot | wagon | 95 | 3485 |
| toyota | wagon | 62 | 3110 |

- **PC3 高**：高马力低车重 → 跑车
- **PC3 低**：低马力高车重 → 旅行车

### 4.2 构造比值特征

```python
df["sports_or_wagon"] = X.curb_weight / X.horsepower
sns.regplot(x="sports_or_wagon", y='price', data=df, order=2)
```

**新特征 = 车重 / 马力**
- 比值小（15-20）→ 马力大车轻 → 跑车
- 比值大（40-50）→ 马力小车重 → 旅行车

### 4.3 regplot 结果：U 型关系

```
价格
  ↑  45000 ·  ← 跑车（比值小，贵）
  |        \
  |         \
  |          \___
  |              \___
  |                  ···  ← 家用车（比值中等，便宜）
  |                      \___
  |                          \___·  ← 旅行车（比值大，又贵了）
  +————————————————————————————→ 比值
   15    20    25    30    35    40    50
```

| 比值范围 | 含义 | 典型车 | 价格 |
|---|---|---|---|
| 15-20（小） | 马力大、车轻 | 保时捷、捷豹等跑车 | 高（3-4.5 万） |
| 25-35（中） | 马力和车重均衡 | 普通家用车 | 最低（0.5-1.5 万） |
| 40-50（大） | 马力小、车重 | 旅行车、MPV | 回升（1.5-2 万） |

**两头贵，中间便宜。**

### 4.4 为什么用 order=2

- 线性模型（`order=1`）会拟合出一条斜向下的直线，完全 miss 掉右边旅行车价格回升的部分
- 二次曲线（`order=2`）才能捕捉到这个 U 型规律

### 4.5 核心价值

**这正是 PCA 成分作为新特征的价值**：PC3 捕捉到了"运动型 vs 旅行型"这个维度，而原始四个特征单独看都看不到这个 U 型关系。通过 `车重/马力` 这个比值特征，把 PC3 的含义**翻译回了业务语言**。

## 五、一页速记

| 困惑 | 澄清 |
|------|------|
| 载荷表怎么看？ | 行=原始特征，列=主成分，值=贡献权重 |
| 同号/异号含义？ | 同号=同向变化，异号=反向变化（形成对比） |
| 载荷矩阵是什么？ | 坐标变换矩阵，把数据从旧坐标系旋转到新坐标系 |
| Explained Variance 怎么算？ | 特征值 / 特征值总和（标准化后总和=特征数） |
| 特征值是什么？ | 协方差矩阵特征分解的结果，= 该方向上的方差大小 |
| 累计方差图用途？ | 决定降到几维（看累计到多少成分覆盖目标百分比） |
| 方差大=对预测有用？ | 不一定，方差大只说明解释数据变化多，不代表对目标变量有用 |
| 如何用 PCA 成分造特征？ | 看载荷表找到对比关系，用原始特征的比值/组合翻译回业务语言 |
| U 型关系怎么处理？ | 用二次多项式（order=2）拟合，线性模型会 miss 掉拐点 |
