## 2. 核心策略：OCR 当载具（为什么这样练不浪费）

### 2.1 桥接表：深入 OCR = 练工业缺陷
| 想深入的复杂 OCR 场景 | 练出的可迁移技能 | 工业缺陷等价物 |
|---|---|---|
| 低质量：模糊/倾斜/反光/光照不均/遮挡 | 预处理(去噪/矫正/透视)、鲁棒增强、困难样本 | 反光/磨损/复杂纹理背景缺陷、光照变化 |
| 密集小文本检测（DBNet 分割式） | 分割式检测、小目标、后处理(二值化/连通域/多边形) | 微米级/细微缺陷、小目标缺陷分割 |
| 复杂版面/表格结构分析 | 区域检测+分割、结构关系建模 | 缺陷分区、多 ROI、结构化输出 |
| 微调 PP-OCR 检测头 on 域数据 | 迁移学习、fine-tune、标注规范、评测(mAP/IoU) | 少量域数据微调缺陷模型 |
| 数据不够 → 合成/增强/主动学习 | 数据合成、augmentation、少样本思路 | 缺陷稀少 → 合成缺陷/少样本/异常检测 |
| 端到端要快 → 部署 | ONNX/TensorRT 量化、端侧推理、C++、延迟优化 | 产线节拍 <50ms、边缘部署 |
| bad case 攻坚（漏检/误检） | bad case 分析、过检漏检优化、阈值调优 | 漏检=不良品流出、误报=停线（核心 KPI） |

### 2.2 重合度
```
想解决的复杂问题  =  低质量/密集小目标/复杂版面/微调/部署/bad case
工业缺陷要的主干  =  检测/分割/鲁棒性/数据合成/部署/bad case + 异常检测
                     ↑ 重合 ~85%，只差 P3 那一块"无监督异常检测"
```

### 2.3 三重红利
工作 OCR 项目同时是：① 工作交付 ② 简历项目（真实数据脱敏版，比 Kaggle 玩具值钱）③ 可迁移技能训练。**现职本身就是缺的"数据入口"。**

## 3. OCR 跑通层级（定位工作任务，别过度投入）

| 层级 | 能做到什么 | 业余耗时 | 说明 |
|---|---|---|---|
| **L0 调现成引擎** | PaddleOCR 直接跑，调角度/语言/预处理 | 1-3 天 ~ 1-2 周 | **工作 cover 到这里即可**，不需深度学习 |
| **L1 微调模型** | 标注域数据，微调 PP-OCR det/rec | 3-6 周 | = P2 的训练场 |
| **L2 复杂场景端到端** | 版面/表格/低质量/bad case 攻坚 | 2-4 个月 | 只投**可迁移**部分 |
| **L3 工程化部署** | ONNX→TensorRT、端侧/C++ | 3-6 个月 | = P4，最正交最保值 |

**工作交付最快路径**：① 先判断 PDF 有无文本层（`pdfplumber`/`PyMuPDF` 能抽就不用 OCR）→ ② 图片型走 PaddleOCR → ③ 表格走 PP-StructureV3 → ④ 抽字段用后处理规则/（不涉密时）多模态 LLM → ⑤ **涉密文档走本地，别传云端**。

## 4. 6 个月主线计划（对着打勾）

### P0 · 交付 + 起步（第 1-3 周）
- [ ] 工作 PDF/图片用 PaddleOCR + PP-Structure 跑通，交付 cover
- [ ] **收集工作 bad case**（识别失败/低质量/复杂版面样本），存为 P2 素材
- [ ] 开刷李沐《动手学深度学习》PyTorch 版（d2l）
- [ ] 环境：Python + PyTorch + GPU（本地或 Colab/AutoDL）

### P1 · 深度学习地基 ⭐（第 4-9 周）— 不能砍
- [ ] d2l 核心章：CNN、训练循环、正则化、优化器
- [ ] 手写 PyTorch 训练循环（不靠高层封装）
- [ ] 跑通 ResNet 图像分类
- [ ] 跑通 YOLO 目标检测（ultralytics），理解原理
- [ ] 练习素材**优先用文本检测/分割**（DBNet 本质是分割，一举两得）
- [ ] **里程碑：能独立训练 + 评估一个模型（看得懂 mAP/IoU/loss 曲线）**

### P2 · 复杂可迁移 OCR 载具 ⭐（第 10-16 周）— 你要的深度在这
- [ ] 深入**文本检测**（DBNet 分割式）：小目标、后处理（二值化/连通域/多边形）
- [ ] **低质量鲁棒性**：模糊/倾斜/反光/光照/遮挡 → 预处理 + 鲁棒增强(albumentations)
- [ ] **微调 PP-OCR 检测头** on 工作域数据（脱敏）：迁移学习 + 标注规范 + 评测
- [ ] **数据合成/增强 pipeline**（为缺陷稀少做准备）
- [ ] **bad case 攻坚**：过检漏检优化、阈值/后处理调优
- [ ] ❌ 跳过：手写体、多语言、CTC 识别精调、文档语义理解
- [ ] **里程碑：一个"复杂场景 OCR"项目（GitHub），每个 hard case 能讲清用了什么可迁移技术**

### P3 · 工业缺陷专精 ⭐（第 17-22 周）— OCR 教不了、必须单独补
- [ ] **无监督异常检测**：MVTec AD + PatchCore/PaDiM（工业缺陷 signature skill）
- [ ] 监督缺陷检测：NEU 表面缺陷 / 天池工业质检赛
- [ ] OpenCV 传统算法：边缘/形态学/模板匹配(Blob/NCC) + 相机标定/畸变校正
- [ ] 少样本/数据合成缺陷（复用 P2 的数据增强能力）
- [ ] **里程碑：GitHub 工业缺陷作品集（异常检测 + 监督检测）← 简历命根子**

### P4 · 部署差异化 + 求职（第 23-26 周）
- [ ] ONNX → TensorRT INT8 量化：**同时部署 OCR 模型 + 缺陷模型**（练两遍）
- [ ] 端侧：Jetson（能借到）/ 否则 ONNXRuntime / OpenVINO(x86)
- [ ] C++ 入门（够写推理服务，非精通）
- [ ] 刷天池/Kaggle 缺陷检测赛，争名次
- [ ] 打包作品集 + README + demo，改简历，投武汉工业视觉岗
- [ ] BOSS 直聘刷 50 个武汉 JD，按真实要求查漏补缺

**时间账**：额外 OCR 深度主要落在 **P2（6-7 周）**，并作为素材贯穿 P1/P3/P4；不砍工业缺陷、不砍部署（本就同一批技能）。C++/Halcon/3D 半年学不完，压到 P4 只做"推理级 + 了解"。

## 6. 三条护栏（守住，否则翻车）

1. **P1 地基 + P3 异常检测不能砍。** 尤其 **P3 无监督异常检测**：OCR 全是监督检测+识别，教不了工业缺陷的核心 signature skill，必须单独补。
2. **工作时间盒。** 若工作把你往手写/多语言/文档语义拽，只做到"够用"，不精调，别陷兔子洞。
3. **每个 hard case 先自检一句**："练的是**可迁移技能**（检测/分割/鲁棒性/部署/数据）还是 **OCR 专属**（CTC/字符集/文档语义）？" → 只深入前者。

## 7. 三盆冷水（预期校准）

1. 6 个月 part-time 从"零 DL"到"job-ready 算法工程师"**有野心**；武汉算法岗普遍 3-5 年 + 常卡硕士、应届入口 1.5%。目标定在"拿入场 offer"。
2. 学历/经验门槛靠**作品集 + 竞赛名次**硬顶——这是命根子，别省。
