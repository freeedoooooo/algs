## 1. 学习方法与心法（零基础必看）

你最大的风险不是"学不会"，而是**"只看视频不动手"**和**"卡在数学上出不来"**。守住这几条：

1. **先跑通，再理解（top-down）。** 每个新概念，先照抄代码跑出结果，看到图/框/loss 下降，再回头懂原理。CV 的好处就是**结果肉眼可见**——用可视化建立直觉（loss 曲线、特征图、检测框、梯度）。
2. **每个概念配一段最小代码。** 学"卷积"就手写跑一次卷积；学"反向传播"就用 numpy 手推一次。不动手 = 没学。
3. **数学 just-in-time，不要先啃完再开始。** 你缺的数学（矩阵乘法、梯度、链式法则）**边学边补**即可，别花一个月单独啃高数。概率统计你已有（特征工程）。
4. **每阶段必须产出一个"能拿出手的小项目"。** 没有产出的学习不算数——项目既是理解检验，也是简历素材。
5. **卡住超过 2 小时就跳过/求助。** 零基础会在细节上卡死；先标记、继续推进、回头再补，别原地消耗。
6. **用 AI 当私教，不当拐杖。** 让 AI 解释概念、review 代码、出练习题；但训练循环、模型结构要自己手敲一遍。

### 数学到底要学多深（预期管理，先吃定心丸）

**结论：整条路线只需要「高中 + 大一」数学，且全程 just-in-time 补，不用单独啃高数。** 框架（PyTorch）把所有计算封装了，你要的是**理解原理**，不是手推公式。

| 阶段 | 用到的数学 | 要求 | 说明 |
|---|---|---|---|
| P1-A/B | 导数、梯度、链式法则 | ⭐ 低 | 懂"梯度=下降最快方向"即可，**不用手推反向传播**（numpy 写一遍是为了理解，不是考试） |
| P1-C/D | 矩阵运算、卷积 | ⭐⭐ 中低 | 卷积=滑动窗口做矩阵乘法；重点看 **shape 怎么变**，计算交给框架 |
| P2 | 概率、阈值、softmax | ⭐⭐ 中低 | 懂"softmax 把分数转概率""阈值卡检测框"即可 |
| P3 | 特征嵌入、距离度量、AUROC | ⭐⭐⭐ 中 | 异常检测=在特征空间比"离正常样本多远"，理解思路即可 |
| P4 | 量化数值（FP16/INT8） | ⭐ 低 | 工程概念，无数学推导 |

> **最难的 CTC Loss（动态规划对齐）你已经整块跳过**——它是纯 OCR 识别专属，你的检测/分割路线用不上。所以**这条路线最难的部分恰好被你砍掉了**，剩下的数学门槛都在"看懂概念"级别。别在数学上自我怀疑。

## 5. P1 · 深度学习地基（周3-10）⭐最关键

> 这是你从零 DL 到"能独立训练模型"的 8 周，**整个计划成败在此**。分 4 个小阶段，每个都有验收标准。

> 🔗 **每周"工作 OCR 回看"锚点（防动机断层，最重要）**：P1 这 8 周是抽象地基，最容易"看不到跟目标的关系"而弃坑。**每周留 1h，把当周学的概念映射回 P0 收集的工作 bad case**，让抽象练习和真实问题绑定：
> - **P1-A（神经网络）**→ 回看："我的模糊样本为什么识别差？"（网络在什么输入下会错）
> - **P1-B（PyTorch 训练）**→ 回看：把 PaddleOCR 当成一个训练好的模型，理解它的输入预处理/输出后处理

## 6. P2 · 复杂可迁移 OCR 载具（周11-16）

> 你要的"深入复杂 OCR"全放这里，但**只深入可迁移的部分**（低质量/密集小目标/检测分割/微调/数据/bad case），兔子洞跳过。

### 桥接逻辑（为什么练这些 = 练工业缺陷）
| 复杂 OCR 场景 | 练出的可迁移技能 | 工业缺陷等价物 |
|---|---|---|
| 低质量：模糊/倾斜/反光/光照/遮挡 | 预处理、鲁棒增强、困难样本 | 反光/磨损/复杂纹理缺陷 |
| 密集小文本检测（DBNet 分割式） | 分割式检测、小目标、后处理 | 微米级/细微缺陷分割 |
| 复杂版面/表格结构 | 区域检测+分割、结构建模 | 缺陷分区、多 ROI |
| 微调 PP-OCR 检测头 on 域数据 | 迁移学习、标注规范、评测 | 少量域数据微调缺陷模型 |
| 数据合成/增强 | augmentation、少样本思路 | 缺陷稀少 → 合成/少样本 |
| bad case 攻坚 | 过检漏检优化、阈值调优 | 漏检=不良品流出（核心 KPI） |

### ❓ 为什么能整块跳过 CTC / 序列建模（识别）？

"序列建模是 OCR 必须的"这句话有个**隐含前提：你要"从零造一个能识别文字的 OCR 系统"**。而本计划**根本不造识别器——只"调用"识别器，从中抽取检测/分割的可迁移技能。** 拆开看：

1. **P0 用的是 PaddleOCR 现成模型**。识别头（含 CTC）对你是一个**黑盒 API**——你调它，它吐字符串。你不需要懂 CTC 才能用它，就像你调 XGBoost 不需要手推梯度提升树的数学。**"必须"是针对"造它的人"，不是"用它的人"。**
2. **P2 深入的是"检测头"（DBNet）+ 预处理 + 鲁棒性 + bad case，唯独不碰识别精调**。上面已明确划掉"CTC 解码精调"。你练的是"把文字/缺陷**框出来、分割出来**"，不是"把图**转成字符串**"。**序列建模只服务后者。**
3. **终点是工业缺陷**，缺陷检测的输出是"框 / 掩码 / 异常分数"，**永远不是一串有序字符**。所以对齐问题（CTC 解决的那个）在你的目标里**根本不存在**。

> **所以这不是"漏了"，而是一次有意的范围切割**：你把 OCR 当载具，只取它"检测 / 分割 / 鲁棒 / 部署"这半截（可迁移），把"识别 / CTC / 字符集"那半截（不可迁移）整块丢掉。序列建模属于被丢掉的那半截——**因为它解决的是"识别"问题，而你从头到尾不做识别。**
>
> **一句话**：guide-ocr 要做完整 OCR（含识别），所以必须教序列建模；你只做 OCR 的"感知 / 检测"部分，所以可以整块跳过。这是**目标不同导致的必然差异，不是疏漏**。
>
> ⚠️ 注意区分：**该跳的是"CTC + 字符识别精调"；不该跳的是"注意力 / Transformer / ViT 的通用理解"**（现代缺陷检测 RT-DETR、ViT backbone、DINO/SAM 都用它）——后者懂原理即可，P1-C 学 ViT、Tier4 学 DINO/SAM 时自然覆盖。

**里程碑**：一个"复杂场景 OCR"GitHub 项目（可用工作脱敏数据），能讲清每处技术选择。

## 7. P3 · 工业缺陷专精（周17-22）⭐ OCR 教不了、必须单独补

> 工业缺陷的核心 signature skill 是**无监督异常检测**（缺陷稀少、常无标注），OCR 全是监督检测+识别，**教不了这块**，必须专门练。

### 周17-18 · 无监督异常检测（重点）
- [ ] **MVTec AD** 数据集（工业缺陷标准 benchmark，下载）
- [ ] **`anomalib`** 库（Intel/OpenVINO 开源，集成 PatchCore/PaDiM/EfficientAD）——跑通 PatchCore
- [ ] 理解：无监督异常检测 vs 监督缺陷分类；特征嵌入 + 记忆库 的思路
- [ ] 评估：AUROC / AP / F1（像素级 + 图像级）

### 周19-20 · 监督缺陷检测

- [ ] 用 YOLO / 分割模型做缺陷定位与分类
- [ ] **类别不均衡**处理（缺陷样本极少）：Focal Loss、重采样、合成缺陷
- [ ] 复用 P2 的数据增强/合成能力

### 周21 · 传统 CV + 标定（工业现场高频）

## 11. 三条护栏

1. **P1 地基 + P3 异常检测不能砍。** 尤其 **P3 无监督异常检测**是工业缺陷的 signature skill，OCR（全监督）教不了，必须单独补。
2. **工作时间盒。** 若工作把你往手写/多语言/文档语义拽，只做到"够用"，不精调，别陷兔子洞。
3. **每个 hard case 先自检一句**："练的是**可迁移技能**（检测/分割/鲁棒性/部署/数据）还是 **OCR 专属**（CTC/字符集/文档语义）？" → 只深入前者。

## 12. 三盆冷水（预期校准）

1. 6 个月 part-time 从"零 DL"到"job-ready 算法工程师"**有野心**；武汉算法岗普遍 3-5 年 + 常卡硕士、应届入口 1.5%。目标定在"拿入场 offer"（应用/初级/中小集成商）。
2. 学历/经验门槛靠**作品集 + 竞赛名次**硬顶——这是命根子，别省。
3. **别把复杂 OCR 做成舒适区**——深入可以，但每个难点必须过护栏 3 的自检，不为"攻克手写体"这种不迁移的难点自我感动。
