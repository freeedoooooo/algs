## 一、PCA 代码三步走

### 1.1 选特征

```python
features = ["highway_mpg", "engine_size", "horsepower", "curb_weight"]
X = df.copy()
y = X.pop('price')
X = X.loc[:, features]
```

选了 4 个和 `price` 相关性高（MI 分数高）的特征：
- `highway_mpg` — 高速油耗（越低说明车越猛）
- `engine_size` — 发动机排量
- `horsepower` — 马力
- `curb_weight` — 整备质量

这四个特征**互相高度相关**（排量大 → 马力大 → 车重 → 油耗高），正好是 PCA 要处理的典型场景。

### 1.2 标准化

```python
X_scaled = (X - X.mean(axis=0)) / X.std(axis=0)
```

把每个特征变成均值 0、标准差 1。

**为什么必须做？** PCA 找的是"方差最大的方向"。如果某个特征数值范围天然就大（curb_weight 是 2000-4000，highway_mpg 是 20-40），PCA 会误以为那个特征"方差大"，其实只是单位不同。标准化让所有特征在同一尺度上公平竞争。

### 1.3 PCA 变换

```python
from sklearn.decomposition import PCA

pca = PCA()
X_pca = pca.fit_transform(X_scaled)

component_names = [f"PC{i+1}" for i in range(X_pca.shape[1])]
X_pca = pd.DataFrame(X_pca, columns=component_names)
```

- `PCA()` 不传参数 → 保留全部 4 个主成分（不降维，只是旋转坐标系）
- `fit` = 学出 4 个主成分的方向（特征向量）
- `transform` = 把原始数据投影到这 4 个新方向上

结果 `X_pca` 还是 4 列（PC1~PC4），但含义变了：

| 原始特征 | PCA 成分 |
|---|---|
| highway_mpg, engine_size, horsepower, curb_weight（互相相关） | PC1, PC2, PC3, PC4（互相正交，不相关） |

- **PC1** 扛了最多的方差（数据差异最大的方向）
- **PC2** 次之，依此类推
- 四个成分加起来 = 原始四个特征的全部信息（没丢）

输出示例：
```
PC1        PC2        PC3        PC4
0.382486  -0.400222   0.124122   0.169539
```

每一行是一辆车，四个值是它在 PC1~PC4 四个新轴上的坐标。这些值**没有原始单位**了，是标准化后的投影值。

下一步通常看 `pca.explained_variance_ratio_`，决定砍掉方差小的成分（如 PC3、PC4）实现降维。

## 二、标准化原理：为什么 (X - mean) / std 能让均值=0、标准差=1

### 2.1 分两步理解

**第一步：减去均值 → 均值变 0**

```
原始数据：[80, 90, 100, 110, 120]    均值 = 100
减去均值：[-20, -10, 0, 10, 20]      均值 = 0
```

所有数据整体平移，中心对齐到 0。正负抵消，均值当然为 0。

**第二步：除以标准差 → 标准差变 1**

```
上面的数据标准差 ≈ 15.8
除以标准差：[-1.27, -0.63, 0, 0.63, 1.27]    标准差 = 1
```

相当于把数据"缩放"，让散布程度变成 1 个单位。

### 2.2 公式验证

设原始数据为 $x$，均值 $\mu$，标准差 $\sigma$，变换后 $z = \frac{x - \mu}{\sigma}$

**均值：**
$$E[z] = E\left[\frac{x - \mu}{\sigma}\right] = \frac{E[x] - \mu}{\sigma} = \frac{\mu - \mu}{\sigma} = 0$$

**标准差：**
$$Std[z] = Std\left[\frac{x - \mu}{\sigma}\right] = \frac{Std[x]}{\sigma} = \frac{\sigma}{\sigma} = 1$$

### 2.3 直觉类比

想象一把尺子：
- **减均值** = 把尺子的"0 刻度"移到数据的中心（原来 0 在尺子最左边，现在 0 在正中间）
- **除以标准差** = 重新定义"1 厘米"的长度，让数据的典型散布范围刚好是 ±1

## 三、z-score 标准化

### 3.1 为什么叫 z-score

**z** 是统计学里给"标准化后的值"起的名字，没有特殊含义，就是一个代号。

就像数学里用 $x$ 表示未知数、$y$ 表示函数值一样，统计学传统上用 **z** 表示标准正态分布上的值。

| 部分 | 含义 |
|---|---|
| **z** | 标准正态分布（均值0、标准差1）上的坐标值 |
| **score** | "得分/分数"，表示一个测量值 |

合起来：**z-score = 在标准尺度上的得分**。

### 3.2 具体例子

某班数学考试：均值 70，标准差 10

| 学生 | 原始分 | z-score 计算 | z-score | 含义 |
|---|---|---|---|---|
| 小明 | 90 | (90-70)/10 | **2.0** | 比平均高 2 个标准差 |
| 小红 | 70 | (70-70)/10 | **0** | 刚好平均 |
| 小刚 | 55 | (55-70)/10 | **-1.5** | 比平均低 1.5 个标准差 |

### 3.3 z-score 的本质

**把不同量纲的数据，翻译到同一个"标准语言"里。**

- 小明的数学 90 分和英语 85 分，能直接比谁更好吗？不能，因为两科均值和难度不同
- 但数学 z=2.0，英语 z=1.5 → 小明数学相对更好

这就是标准化的核心价值：**消除量纲，让不同特征可以公平比较和组合**。PCA 需要这个前提，否则数值范围大的特征会主导结果。
