## 一、K-Means 簇距离特征

### 1.1 距离特征的数量 = n_clusters，与原始特征数无关

```python
kmeans = KMeans(n_clusters=10, n_init=10, random_state=0)
X_cd = kmeans.fit_transform(X_scaled)   # shape = (n_samples, 10)
```

- `fit_transform` 返回**每个样本到每个质心的距离**，矩阵形状为 `(样本数, 簇数)`。
- 10 个质心 → 每样本 10 个距离值 → **10 个新特征**（Centroid_0 ~ Centroid_9）。
- 易错点：误以为距离特征数 = 原始特征数（如 3 个）。**距离特征数只由 k 决定。**

对照：

| 方法 | 返回值 | 形状 |
|------|--------|------|
| `fit_predict` | 簇标签 | (n_samples,) |
| `fit_transform` | 到各质心的距离矩阵 | (n_samples, n_clusters) |

### 1.2 这是"升维"，不是"降维"

```
原始特征 3 个 + 距离特征 10 个 = 13 个特征   （3 → 13，维度增加）
```

- K-Means 的"概括"（20000 样本 → 10 个质心）只是**中间步骤**；
- 特征工程用的是"每个样本到质心的距离"（20000×10 = 200000 个值），是**扩展**而非压缩。
- 结论：**没有降维、没有压缩，只有特征扩展。**

### 1.3 为什么升维能提升模型能力

核心：**不是"维度多就好"，而是"新维度包含了原始维度没有的结构化信息"。**

- 原始特征描述"你是什么"（属性），关系复杂、非线性；
- 距离特征描述"你在哪里"（空间位置），把复杂的非线性关系变成简单的线性关系；
- 例：房价与（面积, 距离）的关系杂糅难学；加入"到市中心/郊区/别墅区质心的距离"后，
  树模型可以用简单规则切分（`distToDowntown < 1 → 高价`）。
- 反例：随机增加的维度（噪声）不含信息，反而有害（维度灾难）。

**一句话：升维的价值不在于"更多"，而在于"更好"——新维度让非线性变线性。**

## 二、PCA 基础概念

### 2.1 核心思想：用"变化的轴"代替原始特征

```
原始描述：鲍鱼 = (Height, Diameter)
PCA描述：鲍鱼 = (Size, Shape)
```

- 数据的主要"变化模式"本身就可以作为新特征；
- **不要描述数据"是什么"，要描述数据"怎么变"。**

### 2.2 载荷（Loadings）：符号与幅度

```
Size  = 0.707 × Height + 0.707 × Diameter    （同符号 → 同向变化 → "大小"）
Shape = 0.707 × Height - 0.707 × Diameter    （反符号 → 反向变化 → "形状"）
```

- **符号**决定成分的含义：同号 = 特征同向变化；异号 = 特征反向变化；
- **幅度**决定贡献度：幅度相同 = 各特征贡献均等。

### 2.3 关键区分：载荷 ≠ 方差（最容易困惑的点）

| 概念 | 含义 | 例子中的值 |
|------|------|-----------|
| 载荷 | 原始特征**如何组合**成成分（权重） | 两个成分都是 0.707 |
| 方差 | 数据沿该成分**分散多少**（信息量） | Size 80%，Shape 20% |

- 载荷相同 ≠ 方差相同：载荷是"组合配方"，方差来自**数据本身的分布**；
- 数据中 Height 与 Diameter 大多同向变化 → Size 方向分散宽（方差大），Shape 方向分散窄（方差小）。

### 2.4 0.707 的几何含义

```
0.707 ≈ √2/2 = cos(45°)
```

- 载荷是**新轴与原始轴夹角的余弦**（方向向量的分量）；
- 两个载荷相等 → 新轴位于原始轴的角平分线 → PCA 把坐标系**旋转了 45°**；
- 约束：载荷平方和 = 1（单位向量），0.707² + 0.707² = 1。

### 2.5 特征分解：PCA 的数学引擎

```
协方差矩阵 → 特征分解 → 特征值（方差大小） + 特征向量（方向/载荷）
最大特征值对应的特征向量 = 第一主成分（PC1）
```

- 数学目标：找单位方向 w 使投影方差 `wᵀ Cov w` 最大 → 拉格朗日求解 → 恰好得到特征方程 `Cov w = λ w`；
- 因此**特征向量 = 数据最分散的方向，特征值 = 该方向的方差**；
- 几何：协方差矩阵描述数据的"椭圆形状"，特征分解找到椭圆的长轴与短轴。

### 2.6 特征向量的直觉：变换后"方向不变"的方向

- 矩阵变换通常会扭曲空间（旋转 + 缩放），大多数向量方向会改变；
- **特征向量 = 只被缩放、不被旋转的特殊方向**（变换的"主轴"）；
- 类比（拉伸照片）：横向拉伸一张照片，横线方向不变只变长（特征向量，特征值=拉伸倍数），
  竖线方向不变（特征值=1），斜线被扭曲（不是特征向量）；
- 对协方差矩阵而言，这些"主轴"就是数据分布的自然坐标轴。

### 2.7 主成分的排序

```
特征值从大到小：λ₁ > λ₂ > ... > λₙ
PC1 = v₁（最大特征值的特征向量），PC2 = v₂，依此类推
```

降维 = 保留前 k 个主成分，丢弃方差小的成分（信息损失最小）。

### 2.8 为什么"方差大 = 信息多"

**信息 = 差异。没有差异就没有信息。方差就是差异的度量。**

- 方差 = 0：所有点坐标相同 → 无法区分谁是谁 → 信息量 0（如"是否是人类"）；
- 方差大：坐标差异明显 → 区分度高 → 信息多（如身高）；
- 投影到某方向后方差小 → 该方向几乎无差异 → 丢弃它损失最小。

## 三、PCA 图像压缩

### 3.1 图像 = 高维向量

- 100×100 灰度图拉平（flatten）= 10000 维向量，每个像素一个维度；
- 2000×2000 图 = 4,000,000 维。

### 3.2 两种应用：样本定义不同，数学相同

| | 应用1：数据集 PCA | 应用2：单图 SVD（低秩近似） |
|---|---|---|
| 样本 = | 一整张图片（1000 个） | 图片的一行扫描线（2000 个） |
| 特征 = | 像素位置（4,000,000 个） | 行内像素（2000 个） |
| 模板含义 | 跨图片共性（特征图/特征脸，稠密整图） | 图内共性（典型行模式） |
| 系数含义 | 描述一张图 | 描述一行 |
| 模板归属 | 全数据集共享（存一次） | 单图私有 |
| 利用的冗余 | 图与图相似 | 行与行相似 |
| 需要数据集 | 需要 | 不需要（单张即可） |
| 模式类比 | 印刷厂：制版一次，批量印刷 | 手绘：每张自给自足 |

**PCA 不知道"样本"是什么——数据摆成矩阵的方式决定成分的含义。**

### 3.3 低秩近似：成分图加权叠加

```
M ≈ σ₁(u₁⊗v₁) + σ₂(u₂⊗v₂) + ... + σₖ(uₖ⊗vₖ)
```

- 每一项 `uᵢ⊗vᵢ`（外积）= 一张 2000×2000 的秩1"成分图"（模糊的幽灵图）；
- 还原 = k 张成分图按权重 σᵢ 加权叠加；
- k 从小到大：k=1 一团光影 → k=10 大致轮廓 → k=100 清晰可辨；
- 成分图不必整张存储：存 uᵢ(2000) + vᵢ(2000) + σᵢ(1) 即可现场算出外积。

### 3.4 压缩从哪来：统一存储公式

```
每个成分的存储 = 模板长度 + 样本个数（σ 可合并进系数）
总存储 = k × (特征维度 + 样本数)
```

| | 应用1 | 应用2 |
|---|---|---|
| k | 50 | 10 |
| 特征维度 | 4,000,000 | 2000 |
| 样本数 | 1000 | 2000 |
| 每成分存储 | 4,000,000 + 1000 | 2000 + 2000 (+1) |
| 总计 | 200,050,000 | 40,010 |
| 每样本边际成本 | 50 个系数 | 10 个系数 |

- 应用2 的 `(2000+2000)`：第一个 2000 = 行模板 vᵢ，第二个 2000 = 2000 行各自的系数 uᵢ；
- 应用1 的模板是**稠密整图**（4,000,000 数/个），拆不成 (m+n)；其"第二个数"是 1000 张图各自的系数（换个角度看即"每图 50 个系数"）；
- 压缩的本质：**秩 k = 所有行躺在 k 维子空间里**，冗余（行间的线性相关）被只存一份模板 + 每行配方取代；
- 前提：数据必须有冗余；纯噪声矩阵满秩，不可压缩。**信息=差异，冗余=没差异=可压缩。**

### 3.5 整图直接 PCA 不可行时的两条路

- 直接对 4,000,000 维做 PCA：协方差矩阵 128TB、O(d³) 计算 → 不可能；
- 路1 **切块**（工业做法）：8×8 小块独立处理，JPEG 的 DCT 就是块上的"固定模板"；
- 路2 **对偶技巧**：n < d 时先分解 n×n 的 Gram 矩阵再换算（Eigenfaces 论文的做法）。

### 3.6 新照片与真实场景

- 模板学好后如"训练好的模型"：新图只需投影（`pca.transform`），不用重学；
- 前提是**同分布**（同类图片），不是"只能压库内图"；
- 不同类 → 重建误差大 → 可检测并兜底（换码本 / 改用通用编码器）；
- 题材漂移 → 定期重学或 IncrementalPCA 增量更新。

**真实世界不这么做的原因：**

1. 50 个系数还原 400 万像素 = 8 万倍压缩 → 糊到认不出，证件照等高精度场景不可接受；
2. PCA 全局基对对齐敏感（人脸偏 1 像素系数全变）；码本私有无法标准化；误差集中在身份关键的高频细节；
3. 存储/传输实际用 JPEG / JPEG2000 / WebP（分块 DCT/小波 + 感知模型 + 标准化）；
4. "存系数"在真实系统里用于**识别而非还原**：人脸特征向量（128~512 维）只做比对，
   且故意不可还原原图（隐私保护特性）。

## 五、Explained Variance 图表解读

### 5.1 两张图的用途

PCA 做完后，用这两张图回答一个问题：**"降维后丢了多少信息？"**

### 5.2 左图：% Explained Variance（每个成分解释了多少方差）

| 成分 | 占比 |
|---|---|
| Size | ~96% |
| Shape | ~4% |

原始数据（Height 和 Diameter 两个维度）中所有的"差异/变化"，PCA 重新组织后，**Size 扛了 96%，Shape 只扛了 4%**。

类比：一张照片，**Size 是拉伸方向**（长宽一起变大变小），**Shape 是变形方向**（一个方向拉长另一个方向压扁）。数据点 96% 的差异是因为整体大小不同，只有 4% 是因为形状不同。

### 5.3 右图：% Cumulative Variance（累计方差）

左图的累加：
- 只保留 Size → 保留 96% 的信息
- 保留 Size + Shape → 100%（两个全保留）

### 5.4 实际用途：决定降到几维

有 100 个特征，PCA 后看累计方差图：
- 前 10 个成分累计到 95% → 砍掉后面 90 个，只留 10 个
- 信息丢了 5%，但维度从 100 降到 10，模型训练快 10 倍

本例中只保留 Size 一个成分，用 1 个维度代替原来 2 个，只丢 4% 信息。

## 六、PCA 成分的四种应用

PCA 产生的成分本身可以直接当特征用，比原始特征更好。

### 6.1 降维（Dimensionality Reduction）

特征高度相关（多重共线）时，PCA 把"重复信息"挤到方差接近 0 的成分里，直接删掉。

类比：两个人描述同一件事说了 100 句，95 句在重复。PCA 把重复部分压缩成 5 句，丢掉废话。

### 6.2 异常检测（Anomaly Detection）

正常数据的变化集中在大方差成分里，**异常数据往往藏在方差很小的成分里**。

类比：工厂流水线 99% 的产品差异只是"大小略有不同"（大方差成分）。偶尔有个产品"形状扭曲了"——在原始维度看不出来，但在 Shape 这个只占 4% 方差的小成分里非常明显。

### 6.3 降噪（Noise Reduction）

多个传感器读数共享同一个背景噪声。PCA 把"真正的信号"集中到少数成分，噪声留在低方差成分中，丢掉即降噪。

类比：10 个人同时录音，每个麦克风都有底噪。PCA 把"大家共同听到的声音"提取出来（信号），把"各自麦克风的嘶嘶声"分离出去（噪声）。

### 6.4 去相关（Decorrelation）

有些算法（线性回归等）在特征高度相关时会出问题。PCA 把相关特征变成**互相正交（相关系数为 0）的成分**，算法更好处理。

类比：原来用"身高+体重+腰围"三个高度相关特征预测，PCA 变成"整体体型+胖瘦比例+其他"三个互不重叠的维度，各管各的。

## 七、多重共线性：为什么特征高度相关会出问题

### 7.1 直观理解

预测房价，特征用 `房屋面积（㎡）` 和 `房屋面积（平方英尺）`。两者本质同一件事，相关系数接近 1.0。

模型困惑：**"房价涨，到底是面积的功劳，还是平方英尺的功劳？"** 没法分配权重，系数剧烈波动——训练集上面积权重 5000，换批数据可能变 -3000。

### 7.2 方程组类比

线性回归本质是解方程组，用数据点拟合超平面，求每个特征的系数。

| 方程组 | 线性回归 |
|---|---|
| 未知数 x, y | 特征系数 w1, w2 |
| 方程个数 = 数据量 | 每个样本一个方程 |
| 方程之间独立 → 唯一解 | 特征之间独立 → 系数稳定 |
| 方程之间成倍数 → 无唯一解 | 特征之间高度相关 → 系数不稳定 |

**情况A：特征独立（方程独立）**
```
x + y = 10
x - y = 2
```
解唯一：x=6, y=4。右边各加 0.1 → x=6.1, y=4.0。**扰动 0.1，系数只变 0.1。稳定。**

**情况B：特征高度相关（方程成倍数）**
```
x + y = 10
1.00x + 1.01y = 10.01
```
解：x=0, y=10。第二条右边从 10.01 变 10.02 → 解变成 **x=-1, y=11**。

**扰动只有 0.01，但 x 从 0 跳到 -1，y 从 10 跳到 11。系数翻了天。**

### 7.3 几何直觉

- **独立特征**：两条线交叉成一个角度，交点很"结实"，线稍微动一点，交点只挪一点点
- **高度相关**：两条线几乎平行，交点很远且很"脆弱"，线稍微动一点，交点就滑出去很远

### 7.4 PCA 怎么解决

PCA 把相关特征变成**正交（互相垂直、相关系数为 0）的成分**。每个成分独立携带信息，不存在"功劳分配"问题，系数稳定可解释。
